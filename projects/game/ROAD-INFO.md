# 도로 상황 정보 연계안: 내 차로 짓는 도시 (`GAM`)

> 상태: **Draft / 2026-11-14**. [USE_CASES.md](USE_CASES.md)의 GAM-UC-006의 도로 상황 퀘스트에 쓸 정보원을 정리합니다. 요구사항의 상태나 우선순위를 정하지 않습니다.
> 실제 API를 호출해 본 결과가 아닙니다. 아래 "확인"은 공식 페이지에 적혀 있다는 뜻입니다.

## 1. 정보원은 두 가지입니다

| 정보 | 출처 | 공모전 범위 | 이 문서의 절 |
|---|---|---|---|
| 경로상의 주의 구간 (공사, 낙석, 사고 다발 구역, 어린이 보호구역 등) | Pleos NaviHelper `onCautionPointInfo`, `onCameraAlert` | [SDK 문서] — 쓸 수 있음 | 2절 |
| 지금 일어난 사고·통제 (실시간 돌발) | 외부 공공 교통정보 API | 외부 API. 공모전에서 써도 되는지 확인 필요(GAM-Q32) | 3절 |

**Pleos SDK와 AAOS에는 실시간 사고 정보가 없습니다.** NaviHelper의 `ACCIDENT_PRONE_AREA`는 "사고 다발 구역"이고, 지금 사고가 났다는 뜻이 아닙니다([dev-environment.md](../../docs/contest/dev-environment.md) 4.4.1절).

## 2. Pleos NaviHelper 주의 구간 (기본 정보원)

- 콜백, 필드, 상수 이름은 [dev-environment.md](../../docs/contest/dev-environment.md) 4.4.1절에 있습니다(2026-11-14 [SDK 문서] 확인).
- 경로 안내 중에만 옵니다. 문서는 "Navigation 앱의 구현 시나리오에 따라 전달되는 이벤트가 달라질 수 있다"고 합니다. 에뮬레이터에서 오는지는 확인하지 않았습니다(GAM-Q31).
- 퀘스트에 쓸 종류 후보와 섬 연출 예시입니다. 어떤 종류를 쓸지는 GAM-Q31에서 정합니다.

| `CautionPointType` | 뜻 | 섬 연출 예시 (Draft) |
|---|---|---|
| `HIGHWAY_CONSTRUCTION` | 고속도로 공사 | 섬 다리에 공사 인부, 지나면 "다 고쳤어요" |
| `FALLING_ROCK_AREA` | 낙석 주의 | 언덕길에 돌 치우는 주민 |
| `ROAD_DAMAGE_ALERT` | 도로 파손 알림 | 길 보수 |
| `SLIPPERY_ROAD_ALERT` | 미끄러운 도로 | 모래 뿌리는 주민 |
| `FOG_AREA` | 안개 구간 | 등대 불빛 |
| `ACCIDENT_PRONE_AREA` | 사고 다발 구역 | 안전 표지판을 세우는 주민. "사고"를 연출하지 않음 |
| `WILDLIFE_CROSSING` | 야생동물 출현 | 섬에 동물 손님 |
| `SCHOOL_ZONE` | 어린이 보호구역 | 안전 지킴이 주민 |
| `RAILROAD_CROSSING`, `DOWNHILL_CAUTION_AREA`, `NARROW_ROAD` | 철길 건널목, 내리막, 좁은 길 | 표지판 |

- 단속(`*_ENFORCEMENT`), 버스 전용차로(`BUS_LANE_*`), 주정차 금지, 교통정보 수집, 신호기 고장, 역주행 경보는 퀘스트에 쓰지 않는 것을 제안합니다. 단속을 퀘스트로 만들면 단속을 피하는 게임처럼 보일 수 있고, 역주행 경보는 위급 상황이라 게임 연출이 어울리지 않습니다.

후보별 응답 항목:

- **UTIC 교통돌발정보** (원문 확인): `incidentId`(고유 아이디), `incidenteTypeCd`(돌발 유형), `incidenteSubTypeCd`(세부 유형), `locationDataX`/`locationDataY`(좌표), `locationTypeCd`(지점·영역·구간), `roadName`(도로명), `lane`(차선), `controlType`(통제 정보), `important`(중요 돌발 여부), `startDate`/`endDate`(발생일·종료일), `updateDate`(갱신 일시) 등. 유형 코드는 돌발정보코드정의서(다운로드 파일)에 있습니다.
- **ITS 돌발상황정보** (검색 요약): 요청 변수 `apiKey`, `type`(도로 유형: `all`, `ex`, `its`, `loc`, `sgg`, `etc`), `eventType`(`all`, `cor` 공사, `acc` 교통사고, `wea` 기상, `ete` 기타돌발, `dis` 재난, `etc`), `getType`(`xml`/`json`), 좌표 범위 `minX`·`maxX`·`minY`·`maxY`(선택). 엔드포인트 이름은 원문으로 확인해야 합니다.
- **서울시 실시간 돌발 정보** (원문 확인): 돌발 유형 코드(OA-13312)와 도로별 링크 정보(OA-13309) 데이터가 함께 필요합니다.

### 제안: 쓴다면 이 순서로 검토합니다

1. **ITS 돌발상황정보**(국토교통부): 전국, 사고(`acc`)·공사(`cor`)를 나눠 받고, 좌표 범위로 경로 근처만 조회할 수 있습니다(검색 요약 기준). 원문 명세와 호출 제한을 먼저 확인해야 합니다.
2. **서울시 실시간 돌발 정보**: 범위가 서울뿐이지만 이용 조건(공공누리 1유형)이 원문으로 확인됐습니다. 서울 시연용으로 적합합니다.
3. UTIC는 IP 인증이라 차량 앱이 직접 부르기 어렵습니다. 중계 서버가 필요합니다.

## 4. 게임에서 쓰는 방식 (GAM-037, Draft P2)

- 앱은 운전자가 경로 안내를 받는 중에만, 경로 근처 좌표 범위로 돌발 정보를 조회합니다. 조회 주기와 범위는 호출 제한을 확인한 뒤 정합니다.
- 경로 근처에 사고·통제가 있으면 섬에 "수습 중" 연출만 보여 줍니다. **주행 중 알림, 운전자 보고, 수습 확인 요청은 하지 않습니다**(GAM-N07).
- 내비가 경로를 다시 탐색(`onReRouteEnded`)했고 목적지에 도착(`onDestinationArrived`)한 뒤 주차하면 "우회 완료"로 완료합니다. 재탐색의 원인을 사고로 단정하지 않습니다.
- 돌발 정보는 "그 기관이 그 시각에 알린 정보"로만 표시합니다. 출처와 조회 시각을 보여 줍니다.

## 5. 지켜야 할 것과 남은 문제

| 항목 | 내용 | 연결 |
|---|---|---|
| 공모전 범위 | 공지는 "공개된 Pleos 개발 문서의 SDK·API 범위에서 개발하고, 문서에서 지원되지 않는 기능은 사용할 수 없다"고 합니다. 외부 웹 API가 이 제한에 걸리는지 확인해야 합니다 | GAM-Q32, 공통 Q11과 같은 성격 |
| 위치 전송 | 좌표 범위로 조회하면 차량의 대략적 위치가 외부 기관 서버로 갑니다. 사용자 승인과 설명이 필요합니다 | AGENTS.md 4절 "승인하지 않은 외부 전송 금지" |
| 인증키 | API 키는 저장소에 커밋하지 않습니다. 차량 앱에 키를 넣으면 노출되므로 중계 서버를 둘지 정해야 합니다 | AGENTS.md 4절 |
| 네트워크 | 차량이 오프라인이면 돌발 정보 없이 2절의 주의 구간 퀘스트만 동작합니다 | GAM-037 대체 동작 |
| 정보 지연·오류 | 이미 수습된 사고가 남아 있거나 늦게 올 수 있습니다. 게임 연출이 사실처럼 보이지 않게 출처와 시각을 붙입니다 | GAM-N07 |
| 시연 | 1차 영상은 실제 API 호출 대신 응답 형식에 맞춘 예시 데이터로 보여 줄 수 있습니다. 예시 데이터라고 화면에 밝힙니다 | [SCENARIO.md](SCENARIO.md) 4절 "가상 데이터 표시" |
