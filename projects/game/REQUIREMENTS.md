## 기능

### GAM-001 주행거리로 건축 자재 적립
- 상태: Draft · 우선순위: P0 · 심사: [차량특화] [기술] · 목표: GAM-G1
- 이야기: 차주로서 이번 운행에서 달린 거리만큼 건축 자재를 받고 싶다. 그래야 운전이 끝날 때마다 도시가 커진다.
- 수용 기준:
  - 운행 시작과 종료 시점의 누적 거리 차이로 자재를 계산한다.
  - 같은 운행을 두 번 적립하지 않는다.
  - Odometer capability가 없으면 적립하지 않고 이유를 보여준다.
- 의존: Vehicle Odometer (CAR_DRIVE) — 문서 확인, 운행 시작·종료 판단 — 확인 필요 (Q8)
- 데모: Virtual Console에서 주행거리를 늘리면 주차 후 자재가 늘어난다
- 메모: 1km당 자재 수(draft 예시 1:1)는 정해야 합니다.
- 출처: draft §01, §04 Odometer

### GAM-002 연료 사용으로 보급 토큰 적립
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [기술] · 목표: GAM-G1
- 이야기: 차주로서 이번 운행의 연료 사용량으로 보급 토큰을 받고 싶다.
- 수용 기준:
  - 연료 상태와 연비로 사용량을 추정하고, 추정값이라고 표시한다.
  - EV는 EvBattery를 쓰거나 다른 기준을 쓴다(GAM-Q9).
- 의존: Vehicle Fuel (CAR_ENERGY) — 문서 확인, EvBattery (CAR_ENERGY) — 문서 확인
- 메모: "더 많이 쓸수록 더 받는" 구조가 친환경 측면에서 괜찮은지 다시 검토합니다(GAM-Q6). 대안은 효율(연비)이나 안전 운전 보상입니다.
- 출처: draft §01, §04 Fuel

### GAM-003 주차 후 운행 결과 화면
- 상태: Draft · 우선순위: P0 · 심사: [차량특화] · 목표: GAM-G1
- 이야기: 차주로서 주차한 직후 차량 화면에서 방금 운행으로 받은 보상과 도시 변화를 바로 보고 싶다.
- 수용 기준:
  - 주차를 감지하면 결과 요약(거리, 자재, 토큰, 다음 정비까지 남은 양)을 보여준다.
  - 주차를 감지할 수 없으면 사용자가 직접 결과 화면을 연다.
- 의존: 주차 판단 (Brake 주차 브레이크, CAR_DRIVE 등) — 확인 필요 (GAM-Q1, Q8)
- 데모: 주차 신호 → 결과 카드 → 도시 화면
- 출처: draft §05 차량특화성

### GAM-006 정비 퀘스트 생성
- 상태: Draft · 우선순위: P0 · 심사: [차량특화] [사업] · 목표: GAM-G2, GAM-G4
- 이야기: 차주로서 마지막 엔진오일 교체 기록을 넣으면, 거리와 기간 중 먼저 오는 기준으로 다음 교체까지 남은 양을 보고 싶다.
- 수용 기준:
  - 교체 기록(날짜, 당시 주행거리)은 사용자가 입력하고, 입력값이라고 표시한다.
  - 차종별 주기를 적용한다. 주기 데이터의 출처를 표시한다.
  - 남은 거리와 남은 기간을 함께 보여주고, 먼저 오는 쪽을 강조한다.
- 의존: Vehicle Odometer (CAR_DRIVE) — 문서 확인, CarInfo (CAR_INFO) — 문서 확인, 차종별 주기 데이터 — 확인 필요 (GAM-Q5), 정비 이력 API — 확인 필요 (GAM-Q4)
- 출처: draft §02

### GAM-009 차량 경고를 도시 이상 현상으로 표현
- 상태: Draft · 우선순위: P0 · 심사: [창의] [차량특화] [기술] · 목표: GAM-G3
- 이야기: 차주로서 차량 경고가 생기면 도시 풍경이 바뀌어 바로 알아차리고 싶다. 동시에 실제 경고 내용과 조치 안내도 보고 싶다.
- 수용 기준:
  - 경고가 오면 해당 도시 효과와 함께 실제 경고명과 안내를 같은 화면에 보여준다.
  - 경고가 풀리면 효과도 끝난다.
  - 차량 신호로 받은 경고만 표시한다. 경고를 추측하지 않는다.
- 의존: Vehicle Safety (CAR_SAFETY) — 문서 확인, Tire (CAR_SAFETY) — 문서 확인, 경고 종류(공기압, 과열) — 확인 필요 (GAM-Q3)
- 데모: Virtual Console에서 공기압 경고 켜기 → 도로 일렁임 + 경고 안내 → 끄기 → 원래대로
- 출처: draft §03, §04 Safety
