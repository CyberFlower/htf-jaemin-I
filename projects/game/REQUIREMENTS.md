## 기능

### GAM-001 주행거리로 건축 자재 적립
- 상태: Draft · 우선순위: P0 · 심사: [차량특화] [기술] · 목표: GAM-G1
- 관련 UC: [USE_CASES.md](USE_CASES.md)의 GAM-UC-001 / B2~B5, A4, E8
- 이야기: 차주로서 이번 운행에서 달린 거리만큼 건축 자재를 받고 싶다. 그래야 운전이 끝날 때마다 도시가 커진다.
- 수용 기준:
  - 운행 시작과 종료 시점의 누적 거리 차이로 자재를 계산한다.
  - 같은 운행을 두 번 적립하지 않는다.
  - Odometer capability가 없으면 적립하지 않고 이유를 보여준다.
- 의존: Vehicle Odometer (CAR_DRIVE) — 문서 확인, 운행 시작·종료 판단 — 확인 필요 (Q8)
- 데모: Virtual Console에서 주행거리를 늘리면 주차 후 자재가 늘어난다
- 메모: 1km당 자재 수(draft 예시 1:1)는 정해야 합니다.
- 출처: draft §01, §04 Odometer

  - 기록하지 않아도 불이익을 주지 않는다. 퀘스트는 📋 퀘스트 현황에 남는다.
- 의존: GAM-006
- 출처: draft §02, SCREENS.md 5절, 2026-11-14 팀 논의
- 관련 결정: [DECISIONS.md](DECISIONS.md) D-002

### GAM-009 차량 경고를 도시 이상 현상으로 표현
- 상태: Draft · 우선순위: P0 · 심사: [창의] [차량특화] [기술] · 목표: GAM-G3
- 이야기: 차주로서 차량 경고가 생기면 도시 풍경이 바뀌어 바로 알아차리고 싶다. 동시에 실제 경고 내용과 조치 안내도 보고 싶다.
- 수용 기준:
  - 경고가 오면 해당 도시 효과와 함께 실제 경고명과 안내를 같은 화면에 보여준다.

  - 차량 신호로 받은 경고만 표시한다. 경고를 추측하지 않는다.
- 의존: Vehicle Safety (CAR_SAFETY) — 문서 확인, Tire (CAR_SAFETY) — 문서 확인, 경고 종류(공기압, 과열) — 확인 필요 (GAM-Q3)
- 데모: Virtual Console에서 공기압 경고 켜기 → 도로 일렁임 + 경고 안내 → 끄기 → 원래대로
- 출처: draft §03, §04 Safety

### GAM-013 운전 습관 기반 정비 주기 조정
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [창의] [기술] · 목표: GAM-G2
- 이야기: 차주로서 단거리 위주로 운전하거나 정체가 많을 때, 고정 주기보다 내 운전 습관에 맞춘 점검 시점을 근거와 함께 알고 싶다.
- 수용 기준:
  - 조정된 시점과 함께 근거(예: "최근 30일 운행의 n%가 5km 미만")를 보여준다.

  - 쓸 수 있는 신호만으로 계산하고, 빠진 신호는 "반영 안 됨"으로 표시한다.
- 의존: Vehicle Odometer 트립 거리·시간 (CAR_DRIVE) — 문서 확인, 공회전·급제동 판단(속도, 시동 상태, Brake 페달) — 확인 필요 (Q8, GAM-Q17), 조정 규칙의 근거 — 확인 필요 (GAM-Q13)
- 데모: 단거리 운행을 여러 번 하면 엔진오일 퀘스트의 점검 시점이 앞당겨지고 근거가 표시된다

### GAM-017 기능 최초 사용 시 튜토리얼 안내
- 상태: Draft · 우선순위: P1 · 심사: [창의] [사업] · 목표: GAM-G1, GAM-G5
- 이야기: 차주로서 새로운 기능을 처음 사용하려 할 때 그 기능의 사용법을 짧게 안내받고 싶다. 그래야 한 번에 모든 설명을 읽지 않아도 필요한 순간에 기능을 이해할 수 있다.
- 수용 기준:
  - 사용자가 보상 결과 조회, 시설 건설, 정비 퀘스트 등 각 기능에 처음 진입하려 할 때 해당 기능의 사용법만 짧게 안내한다. 앱 최초 실행 시 모든 기능을 한꺼번에 설명하지 않는다.
  - 안내는 해당 기능 화면에서 설명 문구와 필요한 조작 위치를 보여주는 방식으로 제공한다. 별도 체험 도시나 가상 자원은 만들지 않는다.

- 데모: 시간을 앞당기면 완성품이 쌓이다가 상한에서 멈추고, 거두면 골드가 늘어난다

### GAM-033 상점 구매와 장식 배치

- 의존: 로컬 저장 — 구현 가능, 장식 그래픽 자산의 제작·이용 권리 — 확인 필요 (GAM-Q12), 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8)

- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [기술] · 목표: GAM-G4, GAM-G5
- 이야기: 운전자로서 누군가와 함께 탈 때 모두 안전벨트를 매고 출발하면 도시 보상을 받고 싶다. 그래야 동승자에게 벨트를 권할 계기가 생긴다.
- 관련 UC: [USE_CASES.md](USE_CASES.md)의 GAM-UC-005 / B2~B4, A1~A3, E2~E4
- 수용 기준:
  - 출발 시점에 점유가 관측된 모든 좌석의 안전벨트 체결이 관측되면 오늘의 "모두 안전벨트" 항목을 달성으로 기록한다.
  - 운전석 외 좌석의 점유가 관측된 날에만 항목을 발급한다. 혼자 탄 날은 항목이 없고 불리하지 않다.
  - 결과는 주차 후 택배 카드 안전운전 칸에 근거(관측한 좌석 수, 체결 관측 여부)와 함께 보여준다. 같은 날 다시 보상하지 않는다(GAM-025).
  - 주행 중에는 미체결을 알리지 않는다. 차량의 안전벨트 경고를 대신하거나 가리지 않는다(GAM-N02, GAM-N06).
  - 점유만 관측되고 체결이 관측되지 않으면 미달성이다. 불이익은 없다.
  - 신호를 읽지 못하거나 출발을 판단할 수 없으면 "판정 불가"로 둔다. 사용자에게 체결을 직접 입력하게 하지 않는다.
- 의존: Vehicle Seat `checkSeatBeltBuckledCapabilities`, `getCurrentSeatBeltBuckledState`, `registerSeatBeltBuckledState` (CAR_SEATS) — 문서 확인, 값의 의미와 에뮬레이터 동작 — 확인 필요 (GAM-Q30), GAM-034, GAM-024, GAM-025, 출발 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 대체 동작: 체결 capability가 없으면 이 항목을 발급하지 않습니다.
- 데모: Virtual Console에서 좌석 점유를 켜고 안전벨트 상태를 바꾼 뒤 출발 → 주차 → 택배 칸에 "모두 안전벨트" 결과(Virtual Console의 벨트 조작 가능 여부는 미검증, GAM-Q30)

### GAM-036 돌발 퀘스트: 도로 주의 구간 안전 통과
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [창의] [기술] · 목표: GAM-G4
- 이야기: 운전자로서 경로에 있던 공사·낙석·사고 다발 구역 같은 주의 구간을 지나온 날, 섬에서도 그 구간이 정리되는 모습을 보고 작은 보상을 받고 싶다.
- 관련 UC: [USE_CASES.md](USE_CASES.md)의 GAM-UC-006 / B1~B4, A1~A2, E1~E5
- 동작: 경로 안내 중 대상 종류의 주의 구간 정보가 오면 돌발 퀘스트를 조용히 만들고, 같은 `id`의 구간을 지난 뒤 주차하면 완료한다.
- 수용 기준:
  - `onCautionPointInfo`로 대상 종류(GAM-Q31)의 주의 구간이 오면 돌발 퀘스트를 만든다. 주행 중 음성·화면 안내를 하지 않는다(내비 안내와 겹치지 않게).
  - 같은 `id`가 목록에서 사라지거나 `remainDistance`가 0이 되면 "지나감"으로 기록한다. 운전 방식은 판정하지 않는다.
  - 지나간 뒤 주차하면 완료하고 골드를 한 번 적립한다. 주차 중 앱을 열면 섬의 정리 완료 연출과 근거(구간 종류, 지나간 시각)를 보여준다.
  - `SCHOOL_ZONE` 구간은 같은 구간에서 어린이 보호구역 카메라 알림(`onCameraAlert`)의 `isOverSpeed`가 참이 아니었을 때만 "안전 통과"로 완료한다. 과속 알림 사실은 주행 중에 알리지 않는다.
  - 내비가 재탐색해 새 경로에 같은 `id`가 없으면 "우회"로 표시하고, 목적지 도착 뒤 주차하면 완료한다. 재탐색 원인을 단정하지 않는다.
  - 구간을 지나기 전에 경로가 취소되거나 운행이 끝나면 보상 없이 만료한다. 불이익은 없다.
  - 하루 보상 횟수에 상한을 둔다(값은 GAM-Q31). 주의 구간을 찾아 다니는 동기가 되지 않게 한다(GAM-N03).
  - `ACCIDENT_PRONE_AREA`를 "사고가 났다"로 표현하지 않는다(GAM-N07).
- 의존: NaviHelper `NaviHelperEventListener` `onCautionPointInfo`(`CautionPoint`: `id`, `type`, `remainDistance`), `onCameraAlert`(`CameraAlert.isOverSpeed`, `type`), `onReRouteEnded`, `onDestinationArrived` — 문서 확인, 에뮬레이터에서 이벤트 수신 — 확인 필요 (GAM-Q31), 백그라운드 수신 — 확인 필요 (GAM-Q25), 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8), GAM-011
- 대체 동작: 경로 안내가 없거나 이벤트가 오지 않으면 퀘스트를 만들지 않습니다. 이벤트가 끊겨 지나감을 확인할 수 없으면 완료하지 않고, 사용자에게 직접 완료를 누르게 하지 않습니다.
- 데모: 경로 안내 중 주의 구간 이벤트 → 주행 중 아무 안내 없음 → 주차 → 섬에 "다 고쳤어요" 연출과 골드(에뮬레이터에서 이벤트를 만드는 방법은 GAM-Q31)
- 출처: 2026-11-14 팀 요청(도로 상황을 퀘스트로, 사고 보고 보상 대신 우회·안전 통과), [ROAD-INFO.md](ROAD-INFO.md) 2절
- 관련 결정: 없음
- 미결정: [GAM-Q31](OPEN_QUESTIONS.md), [GAM-Q25](OPEN_QUESTIONS.md), [GAM-Q1](OPEN_QUESTIONS.md)
- 메모: 우선순위 P1은 에이전트 제안입니다. 섬 연출 예시는 [ROAD-INFO.md](ROAD-INFO.md) 2절.

### GAM-037 돌발 퀘스트: 외부 실시간 돌발 정보 구간 우회
- 상태: Draft · 우선순위: P2 · 심사: [차량특화] [창의] [사업] · 목표: GAM-G4
- 이야기: 운전자로서 경로 근처에 실제 사고나 통제가 있던 날, 섬에도 "수습 중"이 보이고 무사히 돌아 도착하면 보상을 받고 싶다.
- 관련 UC: [USE_CASES.md](USE_CASES.md)의 GAM-UC-006 / A3
- 수용 기준:
  - 경로 안내 중에만, 사용자가 승인한 경우에만 외부 공공 API로 경로 근처의 실시간 돌발 정보를 조회한다(위치가 외부로 감).
  - 경로 근처에 사고·통제가 있으면 섬에 "수습 중" 연출만 보여준다. 연출에는 출처 기관과 조회 시각을 붙인다.
  - 운전자에게 사고 보고, 수습 확인, 사진을 요구하지 않는다(GAM-N07). 주행 중 알림이 없다.
  - 내비 재탐색 뒤 목적지에 도착해 주차하면 "우회 완료"로 완료하고 골드를 한 번 적립한다. 재탐색의 원인을 사고로 단정하지 않는다.
  - 조회에 실패하거나 오프라인이면 이 퀘스트를 만들지 않고 GAM-036만 동작한다.
- 의존: 외부 실시간 돌발 정보 API(ITS 돌발상황정보, 서울시 실시간 돌발 정보 등) — 확인 필요 (GAM-Q32, [ROAD-INFO.md](ROAD-INFO.md) 3절), NaviHelper `onReRouteEnded`, `onDestinationArrived` — 문서 확인, 인증키 관리 — 확인 필요 (GAM-Q32)
- 대체 동작: 외부 API를 쓸 수 없으면 GAM-036의 주의 구간 퀘스트로 대신합니다.
- 데모: 1차 영상은 응답 형식에 맞춘 예시 데이터로 "수습 중" 연출을 보여줄 수 있습니다. 예시 데이터라고 화면에 밝힙니다
- 출처: 2026-11-14 팀 요청(실시간 사고 정보를 알아오는 외부 API), [ROAD-INFO.md](ROAD-INFO.md) 3·4절
- 관련 결정: 없음
- 미결정: [GAM-Q32](OPEN_QUESTIONS.md)
- 메모: 우선순위 P2는 에이전트 제안입니다. 외부 API 사용 가능 여부와 위치 전송 승인이 정해지기 전에는 시연용 예시 데이터로만 보여줍니다.
