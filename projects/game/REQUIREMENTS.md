## 기능

### GAM-001 주행거리로 건축 자재 적립
- 상태: Draft · 우선순위: P0 · 심사: [차량특화] [기술] · 목표: GAM-G1
- 이야기: 차주로서 이번 운행에서 달린 거리만큼 건축 자재를 받고 싶다. 그래야 운전이 끝날 때마다 도시가 커진다.
- 수용 기준:
  - 운행 시작과 종료 시점의 누적 거리 차이로 자재를 계산한다.
  - 같은 운행을 두 번 적립하지 않는다.
  - Odometer capability가 없으면 적립하지 않고 이유를 보여준다.
- 의존: Vehicle Odometer (CAR_DRIVE) — 문서 확인, 운행 시작·종료 판단 — 확인 필요 (Q8)
- 데모: Virtual Console에서 주행거리를 늘리면 주차 후 자재가 늘어난다
- 메모: 1km당 자재 수(draft 예시 1:1)는 정해야 합니다.
- 출처: draft §01, §04 Odometer

- 의존: 주차 판단 (Brake 주차 브레이크, CAR_DRIVE 등) — 확인 필요 (GAM-Q1, Q8)
- 데모: 주차 신호 → 결과 카드 → 도시 화면

### GAM-009 차량 경고를 도시 이상 현상으로 표현
- 상태: Draft · 우선순위: P0 · 심사: [창의] [차량특화] [기술] · 목표: GAM-G3
- 이야기: 차주로서 차량 경고가 생기면 도시 풍경이 바뀌어 바로 알아차리고 싶다. 동시에 실제 경고 내용과 조치 안내도 보고 싶다.
- 수용 기준:
  - 경고가 오면 해당 도시 효과와 함께 실제 경고명과 안내를 같은 화면에 보여준다.

  - 차량 신호로 받은 경고만 표시한다. 경고를 추측하지 않는다.
- 의존: Vehicle Safety (CAR_SAFETY) — 문서 확인, Tire (CAR_SAFETY) — 문서 확인, 경고 종류(공기압, 과열) — 확인 필요 (GAM-Q3)
- 데모: Virtual Console에서 공기압 경고 켜기 → 도로 일렁임 + 경고 안내 → 끄기 → 원래대로
- 출처: draft §03, §04 Safety

### GAM-013 운전 습관 기반 정비 주기 조정
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [창의] [기술] · 목표: GAM-G2
- 이야기: 차주로서 단거리 위주로 운전하거나 정체가 많을 때, 고정 주기보다 내 운전 습관에 맞춘 점검 시점을 근거와 함께 알고 싶다.
- 수용 기준:
  - 조정된 시점과 함께 근거(예: "최근 30일 운행의 n%가 5km 미만")를 보여준다.

  - 조정 규칙의 출처를 표시한다. 출처가 없으면 조정하지 않고 기본 주기를 쓴다.
  - 쓸 수 있는 신호만으로 계산하고, 빠진 신호는 "반영 안 됨"으로 표시한다.
- 의존: Vehicle Odometer 트립 거리·시간 (CAR_DRIVE) — 문서 확인, 공회전·급제동 판단(속도, 시동 상태, Brake 페달) — 확인 필요 (Q8, GAM-Q17), 조정 규칙의 근거 — 확인 필요 (GAM-Q13)
- 데모: 단거리 운행을 여러 번 하면 엔진오일 퀘스트의 점검 시점이 앞당겨지고 근거가 표시된다
- 출처: draft care Feature 01, 시나리오 1 매트릭스

### GAM-017 기능 최초 사용 시 튜토리얼 안내
- 상태: Draft · 우선순위: P1 · 심사: [창의] [사업] · 목표: GAM-G1, GAM-G5
- 이야기: 차주로서 새로운 기능을 처음 사용하려 할 때 그 기능의 사용법을 짧게 안내받고 싶다. 그래야 한 번에 모든 설명을 읽지 않아도 필요한 순간에 기능을 이해할 수 있다.
- 수용 기준:
  - 사용자가 보상 결과 조회, 시설 건설, 정비 퀘스트 등 각 기능에 처음 진입하려 할 때 해당 기능의 사용법만 짧게 안내한다. 앱 최초 실행 시 모든 기능을 한꺼번에 설명하지 않는다.
  - 안내는 해당 기능 화면에서 설명 문구와 필요한 조작 위치를 보여주는 방식으로 제공한다. 별도 체험 도시나 가상 자원은 만들지 않는다.
  - 사용자가 `확인` 또는 `건너뛰기`를 선택하면 해당 기능을 계속 사용할 수 있다.
  - 안내를 확인하거나 건너뛴 여부는 기능별로 저장한다. 이미 안내를 거친 기능에는 다시 자동으로 표시하지 않으며, 설정에서 설명을 다시 볼 수 있다.
- 의존: GAM-003, GAM-004, GAM-006, GAM-009, GAM-N01, GAM-N02, 기능별 로컬 안내 이력, 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 메모: 첫 시설 건설 진입 → 간단한 배치 안내 → 건너뛰기 후 건설 → 재진입 시 안내 생략 → 첫 정비 퀘스트 진입 시 별도 안내 표시.
- 출처: 팀 제안 (게임의 기능별 최초 사용 튜토리얼 방식)

### GAM-018 운행 보상 산정 근거 조회
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [기술] · 목표: GAM-G1
- 이야기: 차주로서 주차 후 받은 자재가 어떤 차량 기록에서 계산됐는지 알고 싶다. 그래야 보상 결과를 신뢰할 수 있다.
- 수용 기준:
  - 결과 상세에 운행 전·후 누적 거리, 계산된 이동 거리, 적용된 자재 변환 기준, 적립 결과를 구분해 보여준다.
  - 운행 경계를 확정할 수 없거나 Odometer 값이 없으면 결과 상세 화면을 비워 두고 안내 문구나 임의의 보상 수치를 표시하지 않는다.
  - 같은 운행의 결과 상세를 다시 열어도 자재가 재적립되지 않는다.
  - 결과 상세를 여는 조작은 주차가 확인된 상태에서만 허용한다.
- 의존: GAM-001, GAM-003, Vehicle Odometer (CAR_DRIVE) — 문서 확인, 운행 경계 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 데모: 주행거리 변화가 있는 결과 카드에서 계산 근거를 펼치고, 데이터가 없을 때는 빈 상세 화면을 확인한다.
- 출처: 팀 제안 (GAM-001의 보상 투명성 보강)

### GAM-019 도시 화면에서 건설 완료 연출
- 상태: Draft · 우선순위: P1 · 심사: [창의] [사업] · 목표: GAM-G1, GAM-G5
- 이야기: 차주로서 시설을 지으면 내 도시에서 건물이 완성되는 모습을 바로 보고 싶다. 그래야 건설의 성취감을 느끼고 도시를 계속 키우고 싶어진다.
- 수용 기준:
  - 건설을 확정하면 현재 도시의 선택한 자리에 시설이 나타난다.
  - 시설이 완성될 때 짧은 건설 완료 효과를 보여주고, 이후에는 완성된 시설이 도시 화면에 남는다.
  - 시설 조합 조건이 충족되면 GAM-005의 조합 효과도 도시 안에서 확인할 수 있다.
  - 자원 부족이나 건설 취소 등으로 건설이 성립하지 않으면 완공 효과를 보여주거나 시설을 추가하지 않는다.
  - 건설과 건설 완료 연출은 주차가 확인된 상태에서만 진행한다. 주행이 시작되면 건설 조작을 중단한다.
- 의존: GAM-004, GAM-005, GAM-N01, 도시 저장 데이터 — 로컬 구현, 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 데모: 도시에서 건설 위치 선택 → 건설 확정 → 해당 위치의 짧은 완공 효과 → 건물이 도시 안에 남는 흐름을 보여준다.
- 출처: 팀 제안 (GAM-G5의 반복 이용 동기 보강)

### GAM-020 시설 배치 미리보기와 건설 취소
- 상태: Draft · 우선순위: P1 · 심사: [창의] · 목표: GAM-G5
- 이야기: 차주로서 모아 둔 자재를 쓰기 전에 시설 위치와 비용을 확인하고 싶다. 그래야 실수로 자원을 소모하지 않는다.
- 수용 기준:
  - 건설 확정 전 미리보기에서 시설의 배치 위치와 소모될 자재·토큰을 보여준다.
  - `취소`하면 자원이 차감되지 않고 도시 배치도 바뀌지 않는다.
  - `확정`할 때 자원이 부족하거나 배치할 수 없는 위치면 건설하지 않고 이유를 보여준다.
  - 주차를 확인할 수 없거나 주행 중이면 미리보기의 확정·배치 조작을 막는다.
- 의존: GAM-004, GAM-N01, 로컬 저장 — 구현 가능, 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 데모: 미리보기 → 취소 → 자원 불변, 미리보기 → 확정 → 시설 및 자원 변경을 순서대로 보여준다.
- 출처: 팀 제안 (시설 건설 사용성 보강)

### GAM-021 도시 꾸미기 테마 전환

  - 테마 선택은 로컬에 저장하고 앱 재실행 후 유지한다. 실결제나 외부 전송은 하지 않는다.

- 데모: 주차 중 테마를 변경하고 시설·자원·퀘스트가 그대로인지 확인한다.

### GAM-022 정비 퀘스트 현황판
- 상태: Draft · 우선순위: P1 · 심사: [차량특화] [사업] · 목표: GAM-G2, GAM-G4
- 이야기: 차주로서 여러 정비 퀘스트 중 지금 확인할 항목을 한곳에서 보고 싶다. 그래야 점검할 일을 놓치지 않는다.
- 수용 기준:
  - 정비 퀘스트마다 항목명, 남은 거리와 기간, `점검 권장` 여부, 기록 출처를 표시한다.
  - 거리 또는 기간 기준에 도달한 항목을 다른 항목보다 먼저 보여준다. 두 기준의 단위가 다르다는 이유로 임의의 수치를 합산하지 않는다.
  - Odometer를 읽을 수 없으면 거리 판단을 `확인 불가`로 표시하고, 확인 가능한 기간 기준만 보여준다.
  - 주차가 확인된 상태에서만 목록을 조작해 정비 기록과 근거를 확인할 수 있다. 주행 중에는 목록 조작을 막고 음성 안내만 허용한다.
- 의존: GAM-006, GAM-008, GAM-011, GAM-N01, Vehicle Odometer (CAR_DRIVE) — 문서 확인
- 데모: 기간이 도래한 퀘스트가 위로 올라오고, 차량 거리 신호를 끊어도 임의의 거리 기반 경고가 생기지 않는지 확인한다.
- 출처: 팀 제안 (다중 정비 퀘스트 탐색성 보강)

### GAM-023 정비 기록 정정과 다음 주기 재계산
- 상태: Draft · 우선순위: P1 · 심사: [사업] [기술] · 목표: GAM-G2
- 이야기: 차주로서 정비 날짜나 당시 주행거리를 잘못 입력했을 때 기록을 고치고 싶다. 그래야 다음 점검 시기를 잘못 안내받지 않는다.
- 수용 기준:
  - 주차가 확인된 상태에서 입력한 정비 기록을 수정하거나 삭제할 수 있다.
  - 수정 전후 값을 확인하고 저장하면 관련 퀘스트의 남은 거리·기간을 다시 계산한다.
  - 기록을 삭제하면 실제 정비가 취소되었다고 단정하지 않고, 기준 기록이 없어 계산할 수 없다고 표시한다.
  - 입력값과 차량에서 읽은 주행거리, 계산된 권장 시점을 구분해 표시한다.
  - 주차 판단이 불가능하면 기록 변경을 막고 조회만 허용한다.
- 의존: GAM-006, GAM-007, GAM-N01, 로컬 정비 기록 — 구현 가능, 주차 판단 — 확인 필요 (GAM-Q1, 공통 Q8)
- 데모: 잘못 입력한 날짜를 수정한 뒤 권장 시점이 변경되고, 기록 삭제 시 계산 불가로 전환되는지 확인한다.
- 출처: 팀 제안 (수동 정비 기록의 오류 복구)
