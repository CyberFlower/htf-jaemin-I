# GOAL: 내 차로 짓는 도시 (`GAM`)

## 한 줄 정의

운행과 소모 기록으로 보상을 얻어 원하는 모습으로 도시를 키우고, 도시를 보러 오는 길에 차량 관리 시기도 알아차린다.

## 기획 의도

- 평소 운전에 "오늘 내 도시는 어떻게 바뀔까?"라는 기대를 더합니다.
- 엔진오일, 에어필터, 타이어 위치 교환 같은 정기 관리는 잊기 쉬워서, 도시를 보러 오는 길에 자연스럽게 알아차리게 합니다.
- 1만 km 같은 획일적인 교체 주기는 단거리 위주나 정체가 많은 운전 습관을 반영하지 못하고, 두꺼운 매뉴얼은 초보 운전자가 찾아보기 어렵습니다.
- 정비 기록 앱, OBD-II 동글 같은 기존 서비스는 폰 중심이라 수동 입력이나 고정 주행거리 기준에 머뭅니다. 차량 화면과 차량 데이터를 쓰면 이 한계를 넘을 수 있습니다.

## 타깃

- 출퇴근, 장보기, 주말 외출 등 일상적으로 차를 운행하며 도시 꾸미기를 즐기는 차주
- 차량 관리가 낯선 초보 운전자, 차를 오래 타고 싶은 장기 보유 운전자

## Goals

| ID | 목표 | 심사 |
|---|---|---|
| GAM-G1 | 주차 직후 차량 화면에서, 방금 이 차로 달린 결과(거리, 연료)가 도시 성장 보상으로 바로 보인다 | `[차량특화]` `[기술]` |
| GAM-G2 | 정기 관리를 퀘스트로 만들어 다음 정비 시기를 알아차리게 한다. 주기는 운전 습관(단거리 비율 등)으로 조정하고, 조정한 근거를 보여준다 | `[차량특화]` `[창의]` `[사업]` |
| GAM-G3 | 실제 차량 경고를 도시의 이상 현상으로 표현하되, 실제 경고와 안내를 함께 보여 안전 정보를 가리지 않는다 | `[창의]` `[차량특화]` |
| GAM-G4 | 퀘스트를 확장할 수 있는 틀로 만들어 정비 알림, 동행 여정(grandma) 등 여러 출처의 목표를 담는다 | `[창의]` `[사업]` |
| GAM-G5 | "일상 운행 → 보상 → 꾸미기 → 다음 운행" 반복 루프와 확장(건축 테마, 시즌 팩) 가설을 지표로 검증할 수 있게 한다 | `[사업]` |
| GAM-G6 | 주행 중에도 시선을 빼앗지 않도록, 차량 사용법과 관리 상태를 음성으로 묻고 답을 듣게 한다 | `[차량특화]` `[기술]` |

## Non-goals

- 주행 중 게임 플레이나 화면 조작
- 실제 경고를 게임 연출로 대체하거나 늦추기
- 과속, 급가속 같은 위험 운전에 유리한 보상
- 실결제와 인앱 구매 구현 (사업 모델은 설명까지만)
- 정비 이력 자동 수집 (차량 API를 확인하지 못했으므로 수동 기록부터)
- 소모품 상태의 진단 확정. 운전 습관 기반 추정은 "점검 권장"까지만 하고, "열화도 8,000km 수준" 같은 단정은 하지 않습니다
- 문서에 없는 차량 제어 API를 전제로 한 기능

## 핵심 루프

| 단계 | 내용 | 차량 데이터 |
|---|---|---|
| 1. 운행 | 이동 거리만큼 건축 자재를 받고(예: 11km → 11개), 안전운전 일일 항목을 달성하면 자재를 더 받습니다 | Odometer, Brake, TurnSignal |
| 2. 주차 후 | 이번 운행 결과를 택배로 받고, 자재를 바로 쓰거나 다음 운행까지 모아 둡니다 | 주차 판단 |
| 3. 건설 | 자재로 시설을 짓고, 시설이 만든 골드로 업그레이드와 장식을 삽니다. 배치에 따라 조합 효과가 납니다(정류장 옆 시장 → 야시장, 공원 옆 무대 → 야외 공연) | 없음 |
| 4. 관리 퀘스트 | 엔진오일 교체까지 1,000km 또는 18일처럼, 마지막 교체 기록에 차종별 주기를 적용해 거리와 기간 중 먼저 오는 기준을 보여줍니다. 교체를 기록하면 퀘스트가 끝나고 다음 주기가 시작됩니다 | Odometer, CarInfo |
| 5. 이상 현상 | 공기압 경고가 오면 도로가 일렁이고, 과열 경고가 오면 광장에 붉은 열기가 피어오릅니다. 실제 경고와 안내를 함께 보여주고, 경고가 풀리면 효과도 끝납니다 | Safety |

예시 수치는 설명용입니다. 보상 비율은 GAM-001에, 재화 역할은 [D-003](DECISIONS.md)에 있습니다.

## 퀘스트 구조

퀘스트 출처를 나눠 두어 새 퀘스트 종류도 같은 틀로 더할 수 있게 합니다(GAM-G4).

| 출처 | 예시 | 완료 조건 | 요구사항 |
|---|---|---|---|
| 안전운전 일일 퀘스트 | 급제동 없이 운전, 방향 지시등 사용 | 주차 후 차량 신호로 판정 | GAM-024~029 |
| 정기 관리 | 엔진오일, 에어필터, 타이어 위치 교환 | 사용자의 교체 기록 | GAM-006~008 |
| 차량이 확인하는 관리 | 엔진오일 양, 워셔액 부족 | 신호가 정상으로 돌아옴 | GAM-048 |
| 차량 경고 | 공기압 경고 해소 | 경고 신호 해제 | GAM-009 |
| 운전 경험 | 장거리 운행 중 쉬어 가기, 모두 안전벨트, 도로 주의 구간 통과 | 차량 신호, 내비 이벤트 | GAM-030, GAM-034~037 |
| 운전 습관 케어 | 단거리 위주 운전이 많을 때 엔진오일 점검을 앞당기는 퀘스트, 배터리 관리 퀘스트 | 점검이나 교체 기록, 배터리 상태 회복 | GAM-013, GAM-014 |
| 동행 여정 | "할머니 모시고 저장한 카페 다녀오기" | 여정 완료 확인 | GAM-012 |

## 차량 관리 요소

차량 관리 기능을 게임 안에 넣었습니다([D-001](DECISIONS.md)).

| 기능 | 게임에서의 형태 | 요구사항 |
|---|---|---|
| 운전 습관에 맞춘 교체 주기 (단거리, 공회전, 급제동) | 정비 퀘스트의 주기를 운전 습관으로 조정 | GAM-013 |
| 배터리 관리와 리프레시 드라이브 | 배터리 관리 퀘스트, 코스 제안 | GAM-014 |
| 음성 차량 매뉴얼 | 음성 조회(GAM-010)를 넓혀 사용법 질문에 답함 | GAM-015 |
| 음성 차량 제어 (열선, 시트) | 범위를 정하지 않음 | GAM-016 |

## 성공 기준 (데모)

- Virtual Console에서 주행거리 값을 바꾸면, 주차 후 화면의 보상이 그에 맞게 바뀐다
- 정비 퀘스트는 교체 기록 입력, 남은 거리와 기간 표시, 기준 도달 시 퀘스트, 완료 후 다음 주기 순서로 이어진다
- 경고 신호를 켜고 끄면 도시 효과와 실제 경고 안내가 함께 나타나고 사라진다
- 주행 중에는 게임 조작이 막히고 안내만 남는다

## 원칙

| 원칙 | 내용 |
|---|---|
| 안전 정보가 먼저 | 경고는 원래 의미 그대로, 게임 효과보다 먼저 또는 함께 보여줍니다 |
| 주행 중에는 조작하지 않음 | 상호작용은 주차 후에만 합니다 |
| 보상은 실제 차량 데이터에 근거 | 사용자가 입력한 값(정비 기록)은 차량 데이터와 구분해 표시합니다 |
| 안전·친환경과 부딪히지 않는 보상 | 연료를 많이 쓸수록 유리한 보상은 넣지 않고([D-002](DECISIONS.md)), 안전운전을 보상합니다 |
| 추정은 추정이라고 말함 | 운전 습관 기반 정비 시점은 근거와 함께 "점검 권장"으로 보여주고, 진단처럼 단정하지 않습니다 |

## 사업성

- 반복 사용 동인: 일상 운행에서 자재가 쌓이고, 다음 운행 뒤 기존 도시를 이어서 꾸밉니다
- 확장 가설: 건축 테마, 시즌 팩
- 사용자 가치: 차량 수명 연장과 유지비 절감
- 측정 지표: 주차 후 앱 열람률, 주간 건설 횟수, 정비 퀘스트 완료율, 경고 확인 후 조치율
