게임 구조:

| 항목 | 내용 |
|---|---|
| 재화 | 건축 자재(운행 거리 → 시설 짓기), 골드(안전운전 일일 항목·돌발 퀘스트·완성품 거두기 → 상점, GAM-033). [SCREENS.md](SCREENS.md) 3절 |
| 운행 보상 | 주차할 때마다 택배가 온다. 거리 자재와 그날 새로 달성한 안전운전 항목의 골드가 한 카드에 담긴다 |
| 일일 퀘스트 | 일정 시간 이상 운전, 급가속·급감속 없이 운전, 급제동 없이 운전, 방향 지시등 사용(GAM-026~029) |
| 돌발 퀘스트 | 장거리 휴식, 정비 시기. 완료하면 골드 |
| 하루 행동 제한 | 쓰다듬기는 횟수 충전(최대 3회), 생산은 시간과 상한으로 제한 |

공통 적용:

- 차량 화면 조작은 주차가 확인된 상태에서만 합니다(GAM-N01). 주행 중에는 짧은 음성 안내만 씁니다.
- 실제 차량 경고가 있으면 퀘스트 안내보다 먼저 또는 함께 보여줍니다(GAM-N02).
- 주행이 시작되면 열린 창을 닫고 확정하지 않은 조작(짓기, 구매, 배치)은 취소합니다. 자원은 차감하지 않고, 생산과 쓰다듬기 충전은 계속됩니다(GAM-N01, GAM-020).
- 운전 행동 퀘스트는 주행 중 피드백과 불이익을 주지 않습니다(GAM-N06). 미달성은 "보상 없음"일 뿐 감점이 아닙니다.
- 신호는 차량의 관측값입니다. 누가 운전했는지 구분하지 않고, "안전하게 운전했다"고 단정하지 않습니다.
- 관련 FR의 수용 기준·검증 태그가 상세 정책의 원천입니다. UC에는 SDK 검증 완료를 새로 주장하지 않습니다.

Goal과의 관계: [GOAL.md](GOAL.md)에는 안전운전 퀘스트를 직접 다루는 Goal이 없습니다. 퀘스트 확장 틀(GAM-G4), 반복 루프(GAM-G5), 원칙 "안전·친환경과 부딪히지 않는 보상"에 연결했습니다. 연료 보상 대신 안전운전 보상을 쓰자는 안([GAM-Q6](OPEN_QUESTIONS.md))과도 이어집니다. GOAL의 퀘스트 구조 표에 일일·돌발 퀘스트를 넣을지는 팀이 정합니다. 2026-11-14에 추가한 운전 경험 퀘스트(GAM-UC-005 동승·안전벨트, GAM-UC-006 도로 주의 구간)도 퀘스트 확장 틀(GAM-G4)에 연결한 제안이며, 퀘스트 구조 표에 출처로 넣을지는 팀이 정합니다.

관련 결정: 아래 미결정의 `GAM-Q#`는 [프로젝트 질문](OPEN_QUESTIONS.md), `공통 Q#`는 [저장소 질문](../../docs/open-questions.md)을 참조합니다.

## GAM-UC-001 운행 후 택배로 보상 받기 (거리 자재, 안전운전 골드)

- 상태: Draft
- 목표: GAM-G4, GAM-G5
- 주 행위자: 운전자
- 보조 행위자: 차량(Odometer 누적 거리·트립 시간, Brake 페달, TurnSignal, AAOS 차량 속도 `PERF_VEHICLE_SPEED`, 주차 판단 신호), Android 권한 시스템(속도 권한 동의 창)
- 사용자 목표: 운행할 때마다 달린 거리만큼 자재를 받고, 평소 운전을 조금 더 안전하게 하고, 그 결과가 매일 도시 보상으로 이어지는 것을 확인하기. 항목은 평소 운전으로 어렵지 않게 완수할 수 있어야 한다
- 범위: 운행 거리 자재 계산, 일일 퀘스트 발급·초기화, 운행 중 신호 관측, 주차 후 판정, 택배 카드 표시, 자재·골드 적립. 자재로 짓는 것은 GAM-UC-003, 골드는 상점에서 쓴다(GAM-033)
- 트리거: 하루가 바뀐 뒤 운전자가 운행을 시작하거나 주차 중에 앱을 연다
- 사전 조건: 오늘의 일일 퀘스트가 발급되어 있다(GAM-024). 운행 중 앱이 화면에 없어도 신호를 받을 수 있다(확인 필요, GAM-Q25)
- 성공 후 조건: 이번 운행의 거리 자재와 새로 달성한 항목의 골드가 한 번만 적립되어 저장된다. 항목별 달성·미달성·판정 불가 상태와 근거가 저장된다
- 실패·취소 후 조건: 판정할 수 없는 항목은 "판정 불가"로 두고 보상을 주지 않는다. 미달성 항목 때문에 기존 자원이나 도시가 줄지 않는다
- 관련 결정: 없음 — [DECISIONS.md](DECISIONS.md)
- 미결정: GAM-Q20(Odometer 없을 때 표시), GAM-Q27(운행 자재 하루 상한), GAM-Q21(운영 규칙·기준값), GAM-Q22(운전 시간 항목의 부작용), GAM-Q23(급가속·급감속·급제동 판정 기준과 속도 시연), GAM-Q24(방향 지시등 판정 기준), GAM-Q25(백그라운드 신호 수집), GAM-Q1·공통 Q8(주차·주행 판단), 공통 Q6(AAOS 권한 승인), GAM-Q2(Virtual Console 시연)
- 출처: 2026-11-13 팀 논의(일일 퀘스트 항목 4종), 2026-11-14 팀 논의, [SCREENS.md](SCREENS.md) S03, [GOAL.md](GOAL.md) 원칙, [GAM-Q6](OPEN_QUESTIONS.md)

### 실행 환경·제약

- 주행·정차: 퀘스트 화면 조작은 주차 중에만 한다. 주행·주차 판단은 확인 필요 — GAM-Q1, 공통 Q8
- 차량 신호:
  - 트립 시간(Odometer)과 브레이크 페달(Brake)은 문서 확인 수준이다
  - TurnSignal은 `getCurrentTurnSignalState`와 상태 콜백으로 읽는다(문서 확인)
  - **속도는 Vehicle SDK에 없고, AAOS `CarPropertyManager`의 `PERF_VEHICLE_SPEED`로 읽는다**(Pleos 차량 앱 FAQ, [dev-environment.md](../../docs/contest/dev-environment.md) 4.3절). 가속도는 프로퍼티가 없어서 속도 변화로 계산한다
  - 주차·주행 판단 후보: AAOS `GEAR_SELECTION`(P단), `PARKING_BRAKE_ON`, `CarUxRestrictionsManager`(4.3절). 어떤 조합을 쓸지는 GAM-Q1, 공통 Q8
  - 에뮬레이터 동작은 미검증이다. Virtual Console에는 속도 항목이 없어서 속도를 바꿔 시연하는 방법을 확인해야 한다 — GAM-Q23, GAM-Q2
- 속도 권한: `Car.PERMISSION_SPEED`는 Dangerous 권한이다. 설치만으로 받을 수 없고 실행 중 사용자 동의가 필요하다
  - 동의 창은 화면 조작이 필요하므로 주차 중에만 띄운다(A5, GAM-N01)
  - 거부해도 앱은 동작한다. 속도를 쓰는 두 항목만 "판정 불가"가 된다(E1)
  - 설정에서 언제든 회수될 수 있으므로 운행을 시작할 때마다 권한을 확인한다
  - AAOS 권한도 App Market·공모전 사전 승인 대상인지는 확인 필요 — 공통 Q6
- 판정 원칙: 급제동은 위험을 피한 결과일 수 있다. 항목은 "시간당 n회 미만"처럼 여유 있게 두고, 미달성에 불이익을 주지 않는다(GAM-N06)
- 운전 시간 항목은 운전을 늘리는 동기가 될 수 있다. 평소 운행으로 채울 수 있는 기준인지 검토한다 — GAM-Q22, GAM-N03

### 실행 환경·제약

- 신호: NaviHelper `NaviHelperEventListener`의 `onCautionPointInfo(List<CautionPoint>)` — `CautionPoint`는 `id`, `type`(`CautionPointType`), `remainDistance`. `onCameraAlert(List<CameraAlert>)` — `type`(`CameraType`), `isOverSpeed`, `speedLimit` 등. `onReRouteEnded`, `onDestinationArrived` — 모두 문서 확인([dev-environment.md](../../docs/contest/dev-environment.md) 4.4.1절). 문서는 "Navigation 앱의 구현 시나리오에 따라 전달되는 이벤트가 달라질 수 있다"고 한다. 에뮬레이터에서 이벤트가 오는지 — 확인 필요(GAM-Q31)
- 대상 종류 후보(팀 결정, GAM-Q31): 도로 상황을 나타내는 `HIGHWAY_CONSTRUCTION`, `FALLING_ROCK_AREA`, `ROAD_DAMAGE_ALERT`, `SLIPPERY_ROAD_ALERT`, `FOG_AREA`, `ACCIDENT_PRONE_AREA`, `WILDLIFE_CROSSING`, `DOWNHILL_CAUTION_AREA`, `NARROW_ROAD`, `RAILROAD_CROSSING`, `SCHOOL_ZONE`. 단속·버스 전용차로·주정차 금지 종류는 넣지 않는다
- 관측과 해석: 주의 구간은 내비가 알려 준 정보다. `ACCIDENT_PRONE_AREA`는 "사고가 났다"는 뜻이 아니라 "사고가 잦은 구역"이다. 섬 연출과 문구도 그 뜻을 넘지 않는다
- 안전: 주행 중 음성·화면 피드백 없음(GAM-N01, GAM-N06). 운전자에게 도로 상황 보고를 요구하지 않음(GAM-N07). 보상은 운전 방식이 아니라 "지나감"으로만 준다(어린이 보호구역 A1만 과속 알림이 없었는지 관측)
- 보상 원칙: 주의 구간을 일부러 찾아가지 않도록 하루 보상 상한을 둔다(값은 GAM-Q31)
