# USE CASES: 내 차로 짓는 도시 (`GAM`)

> 상태: **Draft — 첫 초안**. UC 분할과 단계 번호는 검토용 정리이며 범위 확정이 아닙니다.
> 기준: [GOAL.md](GOAL.md), [REQUIREMENTS.md](REQUIREMENTS.md), [원본 기획안 v0.1](../../draft/proposal-game.png), 2026-11-13 팀 논의(일일 퀘스트 항목, 돌발 퀘스트).
> 형식: [공통 UC·FR 템플릿](../../docs/process/templates/README.md). 원본보다 Goal·현재 FR을 우선하며, 문서에 없는 정책은 질문으로 남깁니다.

## UC 목록과 기존 요구사항

| UC | 사용자 목표 | 관련 FR | 기존 FR 우선순위 |
|---|---|---|---|
| GAM-UC-001 | 일일 퀘스트로 안전운전하고 보상 받기 | GAM-024~029, GAM-N06 | 신규 (Draft P1) |
| GAM-UC-002 | 장거리 운행 중 돌발 퀘스트로 쉬어 가기 | GAM-030, GAM-N06 | 신규 (Draft P1) |

일일 퀘스트의 네 항목(운전 시간, 급가속·급감속, 급제동, 방향 지시등)은 같은 흐름에서 판정 대상만 달라서 UC 하나로 두고, 항목별 신호와 기준은 FR로 나눴습니다. 돌발 퀘스트는 연속 운전이라는 다른 사건으로 시작하므로 UC를 나눴습니다.

공통 적용:

- 차량 화면 조작은 주차가 확인된 상태에서만 합니다(GAM-N01). 주행 중에는 짧은 음성 안내만 씁니다.
- 실제 차량 경고가 있으면 퀘스트 안내보다 먼저 또는 함께 보여줍니다(GAM-N02).
- 운전 행동 퀘스트는 주행 중 피드백과 불이익을 주지 않습니다(GAM-N06). 미달성은 "보상 없음"일 뿐 감점이 아닙니다.
- 신호는 차량의 관측값입니다. 누가 운전했는지 구분하지 않고, "안전하게 운전했다"고 단정하지 않습니다.
- 관련 FR의 수용 기준·검증 태그가 상세 정책의 원천입니다. UC에는 SDK 검증 완료를 새로 주장하지 않습니다.

Goal과의 관계: [GOAL.md](GOAL.md)에는 안전운전 퀘스트를 직접 다루는 Goal이 없습니다. 퀘스트 확장 틀(GAM-G4), 반복 루프(GAM-G5), 원칙 "안전·친환경과 부딪히지 않는 보상"에 연결했습니다. 연료 보상 대신 안전운전 보상을 쓰자는 안([GAM-Q6](OPEN_QUESTIONS.md))과도 이어집니다. GOAL의 퀘스트 구조 표에 일일·돌발 퀘스트를 넣을지는 팀이 정합니다.

관련 결정: 아래 미결정의 `GAM-Q#`는 [프로젝트 질문](OPEN_QUESTIONS.md), `공통 Q#`는 [저장소 질문](../../docs/open-questions.md)을 참조합니다.

## GAM-UC-001 일일 퀘스트로 안전운전하고 보상 받기

- 상태: Draft
- 목표: GAM-G4, GAM-G5
- 주 행위자: 운전자
- 보조 행위자: 차량(Odometer 트립 시간, Brake 페달, TurnSignal, AAOS 차량 속도 `PERF_VEHICLE_SPEED`, 주차 판단 신호), Android 권한 시스템(속도 권한 동의 창)
- 사용자 목표: 평소 운전을 조금 더 안전하게 하고, 그 결과가 매일 도시 보상으로 이어지는 것을 확인하기. 항목은 평소 운전으로 어렵지 않게 완수할 수 있어야 한다
- 범위: 일일 퀘스트 발급·초기화, 운행 중 신호 관측, 주차 후 판정·결과 표시·보상 적립. 보상으로 시설을 짓는 것은 다른 UC(미작성, GAM-004)로 넘긴다
- 트리거: 하루가 바뀐 뒤 운전자가 운행을 시작하거나 주차 중에 앱을 연다
- 사전 조건: 오늘의 일일 퀘스트가 발급되어 있다(GAM-024). 운행 중 앱이 화면에 없어도 신호를 받을 수 있다(확인 필요, GAM-Q25)
- 성공 후 조건: 달성한 항목의 보상이 한 번만 적립되어 저장된다. 항목별 달성·미달성·판정 불가 상태와 근거가 저장된다
- 실패·취소 후 조건: 판정할 수 없는 항목은 "판정 불가"로 두고 보상을 주지 않는다. 미달성 항목 때문에 기존 자원이나 도시가 줄지 않는다
- 관련 결정: 없음 — [DECISIONS.md](DECISIONS.md)
- 미결정: GAM-Q21(운영 규칙·기준값), GAM-Q22(운전 시간 항목의 부작용), GAM-Q23(급가속·급감속·급제동 판정 기준과 속도 시연), GAM-Q24(방향 지시등 판정 기준), GAM-Q25(백그라운드 신호 수집), GAM-Q1·공통 Q8(주차·주행 판단), 공통 Q6(AAOS 권한 승인), GAM-Q2(Virtual Console 시연)
- 출처: 2026-11-13 팀 논의(일일 퀘스트 항목 4종), [GOAL.md](GOAL.md) 원칙, [GAM-Q6](OPEN_QUESTIONS.md)

### 실행 환경·제약

- 주행·정차: 퀘스트 화면 조작은 주차 중에만 한다. 주행·주차 판단은 확인 필요 — GAM-Q1, 공통 Q8
- 차량 신호:
  - 트립 시간(Odometer)과 브레이크 페달(Brake)은 문서 확인 수준이다
  - TurnSignal은 `getCurrentTurnSignalState`와 상태 콜백으로 읽는다(문서 확인)
  - **속도는 Vehicle SDK에 없고, AAOS `CarPropertyManager`의 `PERF_VEHICLE_SPEED`로 읽는다**(Pleos 차량 앱 FAQ, [dev-environment.md](../../docs/contest/dev-environment.md) 4.3절). 가속도는 프로퍼티가 없어서 속도 변화로 계산한다
  - 주차·주행 판단 후보: AAOS `GEAR_SELECTION`(P단), `PARKING_BRAKE_ON`, `CarUxRestrictionsManager`(4.3절). 어떤 조합을 쓸지는 GAM-Q1, 공통 Q8
  - 에뮬레이터 동작은 미검증이다. Virtual Console에는 속도 항목이 없어서 속도를 바꿔 시연하는 방법을 확인해야 한다 — GAM-Q23, GAM-Q2
- 속도 권한: `Car.PERMISSION_SPEED`는 Dangerous 권한이다. 설치만으로 받을 수 없고 실행 중 사용자 동의가 필요하다
  - 동의 창은 화면 조작이 필요하므로 주차 중에만 띄운다(A5, GAM-N01)
  - 거부해도 앱은 동작한다. 속도를 쓰는 두 항목만 "판정 불가"가 된다(E1)
  - 설정에서 언제든 회수될 수 있으므로 운행을 시작할 때마다 권한을 확인한다
  - AAOS 권한도 App Market·공모전 사전 승인 대상인지는 확인 필요 — 공통 Q6
- 판정 원칙: 급제동은 위험을 피한 결과일 수 있다. 항목은 "시간당 n회 미만"처럼 여유 있게 두고, 미달성에 불이익을 주지 않는다(GAM-N06)
- 운전 시간 항목은 운전을 늘리는 동기가 될 수 있다. 평소 운행으로 채울 수 있는 기준인지 검토한다 — GAM-Q22, GAM-N03
- 네트워크·외부 전송: 해당 없음. 기록과 판정은 로컬에서 한다

## GAM-UC-002 장거리 운행 중 돌발 퀘스트로 쉬어 가기

- 상태: Draft
- 목표: GAM-G4
- 주 행위자: 운전자
- 보조 행위자: 차량(Odometer 트립 시간, 주차 판단 신호), TextToSpeech
- 사용자 목표: 오래 운전할 때 쉬어 갈 시점을 알고, 쉬어 가면 도시 보상도 받기
- 범위: 연속 운전 시간 관측, 돌발 퀘스트 생성과 음성 안내, 주차 시간으로 완료 판정, 보상 적립. 휴게소 경로 제안·안내(NaviHelper)는 이 UC 범위 밖이다
- 트리거: 연속 운전 시간이 기준 시간을 넘는다(기준은 GAM-Q26)
- 사전 조건: 운행 중 트립 시간을 받을 수 있다(GAM-Q25). 같은 운행에서 아직 돌발 퀘스트가 생기지 않았다
- 성공 후 조건: 휴식 인정 시간 이상 주차하면 돌발 퀘스트가 완료되고 보상이 한 번 적립된다
- 실패·취소 후 조건: 쉬지 않고 운행을 마치면 퀘스트는 보상 없이 만료된다. 불이익은 없다
- 관련 결정: 없음 — [DECISIONS.md](DECISIONS.md)
- 미결정: GAM-Q26(기준 시간·휴식 인정 시간·재안내·보상 상한), GAM-Q25(백그라운드 신호, 트립 시간 의미), GAM-Q1·공통 Q8(주차 판단), GAM-Q7·공통 Q7(음성)
- 출처: 2026-11-13 팀 논의(장거리 운행 중 쉬어 가기를 돌발 퀘스트로)

| B2 | 운전자가 휴게소 등에 차를 세우고 주차한다 | 주차 시작 시각을 기록한다 |
| B3 | 운전자가 휴식 인정 시간 이상 주차를 유지한다 | 돌발 퀘스트를 완료하고 보상을 한 번 적립한다 |
| B4 | 운전자가 주차 중에 앱을 연다 | 완료 결과와 근거(연속 운전 시간, 주차 시간), 받은 보상을 보여준다 |

### 실행 환경·제약

- 주행 중 상호작용: 음성 안내 한 번만 한다. 응답이나 화면 조작을 요구하지 않는다(GAM-N01)
- 차량 신호: 트립 시간(Odometer)은 문서 확인 수준이다. 트립 시간이 언제 초기화되고 정차 시간을 포함하는지는 확인 필요 — GAM-Q25
- 주차 판단 후보: AAOS `GEAR_SELECTION`(P단), `PARKING_BRAKE_ON`([dev-environment.md](../../docs/contest/dev-environment.md) 4.3절). 어떤 조합을 쓸지는 GAM-Q1, 공통 Q8
- 관측과 해석: 주차 시간을 기록할 뿐 "휴식했다"고 단정하지 않는다. 신호 대기 같은 짧은 정차는 주차가 아니므로 휴식 시간에 넣지 않는다
- 보상 원칙: 돌발 퀘스트를 받으려고 오래 운전하게 만들면 안 된다. 하루 보상 횟수 상한 등은 GAM-Q26, GAM-N03
- 기준 시간과 휴식 인정 시간은 공개 근거가 필요하다. 근거 없이 수치를 정하지 않는다 — GAM-Q26
- 확장 후보(범위 밖): 정차 중 휴게소 경로 제안. 사용자 승인 후에만 내비게이션에 적용한다(NaviHelper `requestRoute()` — 문서 확인)
