# 화면 구성 (제안): 내 차로 짓는 도시 (`GAM`)

> 상태: Draft (제안). 공모전(1차 2026-11-15 제출, 2차 2026-12-03 PT)에서 보여줄 장면과 그에 필요한 화면을 제안합니다. 채택 여부는 팀이 정합니다.
> 화면 ID(`S##`)는 이 문서 안에서만 쓰는 표기입니다.

## 1. 보여줄 것

- **감성형 방치 게임:** 아이소메트릭 섬, 주민, 낮·밤 불빛. 바탕에 띄워 두고 보는 게임입니다.
- **매일 짧게 들르는 게임:** 주차할 때마다 택배, 완성품, 쓰다듬을 주민이 기다리고 있습니다. 몇 분이면 그날 할 일이 끝나고, 주행 중에는 섬이 알아서 돌아갑니다.
- **차와 이어진 게임:** 운행은 짓기 재료가 되고, 정비 시기와 차량 경고가 섬에 나타납니다.

## 2. 임팩트 장면

| # | 장면 | 화면 | 심사 | 요구사항 |
|---|---|---|---|---|
| 1 | 주행 중에는 섬만 움직이고 조작이 없음. "주행 중이에요" 한 줄 | S02 | `[차량특화]` | GAM-N01 |
| 2 | 주차하면 내 차가 섬으로 돌아오고 정류장에 택배 트럭. 열면 "11km · 자재 11개", 그리고 "급제동 없이 ✓ 골드 +30" | S03 | `[차량특화]` `[기술]` | GAM-001, GAM-003, GAM-025 |
| 3 | 빈 땅을 눌러 시장을 짓고, 저녁이 되면 정류장 옆 시장이 야시장으로 바뀜 | S04, S05 | `[창의]` | GAM-004, GAM-005, GAM-019 |
| 4 | 빵집의 완성품을 거둬 골드를 받고, 상점에서 장식을 사서 광장에 놓음 | S06, S11, S12 | `[사업]` | GAM-031, GAM-033 |
| 5 | 정비소 주민이 엔진오일 점검 시기를 알려줌. 거리와 기간 중 먼저 오는 쪽 | S08, S09 | `[차량특화]` `[사업]` | GAM-006, GAM-007 |
| 6 | 공기압 경고가 오면 실제 경고 카드가 맨 위에 뜨고, 섬의 길이 일렁임 | S10 | `[창의]` `[차량특화]` | GAM-009, GAM-N02 |

## 3. 자원

| 자원 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 건축 자재 ▣ | 운행(주행거리, 하루 상한) — 택배 | 시설 짓기 |
| 골드 ● | 안전운전 일일 항목 — 택배, 돌발 퀘스트, 시설 완성품 거두기 | 상점 |

- 운전으로 얻는 자재의 하루 상한은 GAM-Q27에서 정합니다(GAM-N03).

## 4. 일일 안전운전과 다시 들를 이유

- 일일 퀘스트: 일정 시간 이상 운전, 급가속·급감속 없이 운전, 급제동 없이 운전, 방향 지시등 사용(GAM-026~029). 결과와 골드는 택배에 담깁니다.
- 운전 시간 항목(GAM-026)은 평소 운행으로 채울 수준으로 두고, 넘겨도 보상이 늘지 않습니다(GAM-N03, GAM-Q22).
- 차량 화면에서만 도는 앱이라 주차가 곧 들를 계기입니다. 다시 들를 이유는 아래 세 가지입니다.

| 이유 | 규칙 |
|---|---|
| 택배 | 주차할 때마다 온다 |
| 완성품 | 시설이 1분당 생산량대로 쌓고, 약 2~3일치까지 쌓인다(GAM-031) |
| 쓰다듬기 | 주민별 쿨타임마다 1회 충전, 최대 3회까지 쌓인다(GAM-032) |

- 연속 접속 보상은 넣지 않습니다. 차량 앱에서는 접속이 곧 운행이라, 운행을 늘리는 동기가 될 수 있기 때문입니다.

## 5. 정비는 차의 알림 (돌발 퀘스트)

- 정비 기준에 닿으면 돌발 퀘스트로 정비소 주민이 알려줍니다(GAM-007, GAM-UC-002). 화면은 차량 정보 스타일로 남은 거리와 기간, 주기의 출처, `점검 권장`을 보여줍니다(GAM-N05).
- 기록하면 정비소 주민이 고맙다고 말하고, 돌발 퀘스트 보상으로 골드를 줍니다(GAM-007).

## 6. 조작

할 일은 섬 위의 물체를 눌러서 합니다. 고정 버튼은 위 줄 아이콘뿐입니다.

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 섬 이름  ▣ 23  ● 140                   P 주차 중 14:32   🛒  📋 3   ⚙ │
│                                                                         │
│   🚚(택배!)            🍞 ← 완성품                                       │
│     정류장 ──── 빵집 ──── 광장(🐶♥ 🦆♥) ──── 꽃집 ──── 상점 🏪          │
│     🚗 내 차          ⋯ 빈 땅 ⋯          정비소 🐱🔧                    │
│                                                                         │
│                     (주민이 돌아다니고 낮·저녁·밤이 바뀜)                │
└─────────────────────────────────────────────────────────────────────────┘
```

| 누르는 것 | 열리는 것 |
|---|---|
| 정류장 🚚 | S03 택배 |
| 빈 땅 | S04 짓기 |
| 완성품 🍞 | 바로 거두기 (골드, 창 없음) |
| 시설 | S06 시설 말풍선 |
| 광장의 주민 (머리 위 ♥) | 쓰다듬기 (♥, 창 없음, 최대 3회 충전) |
| 상점 🏪 또는 위 줄 🛒 | S11 상점 |
| 정비소 | S08 차량 관리 |
| 📋 | S07 퀘스트 현황 (화면을 덮는 전체 화면) |

| S03 | 택배 | 카드 | 🚚 | 달린 거리와 자재, 안전운전 칸(항목별 결과와 골드), 다음 정비까지 남은 양, [근거] [받기] | 1차 |

| S06 | 시설 말풍선 | 말풍선 | 시설 | 쌓인 양, 상한까지 남은 시간, [거두기] | 2차 |

| S08 | 차량 관리 | 전체 화면 | 정비소, 기준 도달 배너 | 남은 거리와 기간, 출처, `점검 권장` | 1차 |

| S12 | 보관함 | 창 | S11, 상점 안 탭 | 산 장식과 개수, 고르면 섬 위 미리보기 → [확정] | 2차 |

## 8. 차량 상태별 동작

| 상태 | 화면 | 조작 |
|---|---|---|
| 주차 | S01과 모든 화면 | 전부 |
| 주행, 정차, 판단 불가 | S02 | 없음 (GAM-N01, GAM-Q11) |
| 실제 경고 | 어떤 화면이든 위에 S10 | 경고가 풀릴 때까지 유지 (GAM-N02) |

주행이 시작되면 열린 창을 닫고 확정하지 않은 짓기·구매·배치는 취소합니다. 자원은 차감하지 않습니다. 생산과 쓰다듬기 충전은 계속됩니다(GAM-020).

## 9. 시연 영상 순서 (1차)

장면별 상세와 목업 연결은 [SCENARIO.md](SCENARIO.md)에 씁니다. 아래 순서를 바꾸면 `SCENARIO.md` 2절 장면 표도 함께 고칩니다([규칙](../../docs/process/submission-package.md)).

| 순서 | 장면 | 화면 |
|---|---|---|
| 1 | 낮의 섬. 주민이 돌아다님 | S01 |
| 2 | 출발 → 주행 모드. 조작 없음 | S02 |
| 3 | 주차 → 차가 돌아옴 → 택배 열기 (자재 + 안전운전 골드) | S03 |
| 4 | 빈 땅에 시장 짓기 → 저녁 야시장 | S04, S05 |
| 5 | 완성품 거두기 → 상점에서 장식 사서 놓기 → 주민 쓰다듬기 | S06, S11 |
| 6 | 정비소 주민의 정비 알림 → 교체 기록 | S08, S09 |
| 7 | 공기압 경고 → 경고 카드 + 길 일렁임 → 해제 | S10 |

## 10. 출시 후 확장 (PT에서 말로만)

주민 인연 스토리, 계절 이벤트와 무료 시즌 패스, 건축 테마, 음성 조회(GAM-010, GAM-015), 운전 습관 기반 정비 주기(GAM-013).
