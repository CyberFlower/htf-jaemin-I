# 화면 구성 (제안): 내 차로 짓는 도시 (`GAM`)

> 상태: Draft (제안). 공모전(1차 2026-11-15 제출, 2차 2026-12-03 PT)에서 보여줄 장면과 그에 필요한 화면을 제안합니다. 채택 여부는 팀이 정합니다.
> 화면 ID(`S##`)는 이 문서 안에서만 쓰는 표기입니다.

## 1. 보여줄 것

- **감성형 방치 게임:** 아이소메트릭 섬, 주민, 낮·밤 불빛. 바탕에 띄워 두고 보는 게임입니다.
- **매일 짧게 들르는 게임:** 서브컬처 게임처럼 하루 몇 분 일일 임무를 끝내면 그날 할 일이 끝납니다(참고: 붕괴: 스타레일 일일 훈련, 블루 아카이브 카페). 주차할 때 들르고, 주행 중에는 섬이 알아서 돌아갑니다.
- **차와 이어진 게임:** 운행은 짓기 재료가 되고, 정비 시기와 차량 경고가 섬에 나타납니다.

## 2. 임팩트 장면

| # | 장면 | 화면 | 심사 | 요구사항 |
|---|---|---|---|---|
| 1 | 주행 중에는 섬만 움직이고 조작이 없음. "주행 중이에요" 한 줄 | S02 | `[차량특화]` | GAM-N01 |
| 2 | 주차하면 내 차가 섬으로 돌아오고 정류장에 택배 트럭. 열면 "11km · 자재 11개" | S03 | `[차량특화]` `[기술]` | GAM-001, GAM-003 |
| 3 | 빈 땅을 눌러 시장을 짓고, 저녁이 되면 정류장 옆 시장이 야시장으로 바뀜 | S04, S05 | `[창의]` | GAM-004, GAM-005, GAM-019 |
| 4 | 일일 임무를 끝내면 그날 숙제 끝. 운전하지 않은 날에도 섬이 자람 | S06, S07 | `[사업]` | FR 후보 |
| 5 | 정비소 주민이 엔진오일 점검 시기를 알려줌. 거리와 기간 중 먼저 오는 쪽 | S08, S09 | `[차량특화]` `[사업]` | GAM-006, GAM-007 |
| 6 | 공기압 경고가 오면 실제 경고 카드가 맨 위에 뜨고, 섬의 길이 일렁임 | S10 | `[창의]` `[차량특화]` | GAM-009, GAM-N02 |

## 3. 자원

| 자원 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 건축 자재 ▣ | 운행(주행거리, 하루 상한), 시설 완성품 거두기, 일일 임무 | 짓기 |
| 행동력 ☀ | 시간이 지나면 참. 하루치까지만 차고 넘치면 버려짐 | 시설에서 생산 걸기 |

- 운전으로 얻는 자재에는 하루 상한을 둡니다. 행동력과 일일 임무로도 자재를 얻으므로 적게 운전해도 섬이 자랍니다(GAM-N03, GAM-Q20).
- 행동력은 넘치면 버려지므로 매일 들를 이유가 됩니다.
- 연료 기반 보급 토큰(GAM-002)은 GAM-Q6 결정 전까지 넣지 않습니다.

## 4. 일일 임무

- 4~5개. 하나에 20점, 활약도 100이면 장식 보상.
- 예: 행동력 60 쓰기 · 완성품 2번 거두기 · 광장 주민 3명 쓰다듬기 · 시설 1개 짓기
- "운행하기", "몇 km 달리기"는 넣지 않습니다(GAM-N03).

## 5. 정비는 차의 알림

- 정비소 주민이 알려주고, 화면은 차량 정보 스타일로 남은 거리와 기간, 주기의 출처, `점검 권장`을 보여줍니다(GAM-N05).
- 기록하면 정비소 주민이 고맙다고 말합니다. 게임 재화는 주지 않습니다. 보상이 크면 정비 없이 기록만 넣을 이유가 생기기 때문입니다(GAM-Q21).

## 6. 조작

할 일은 섬 위의 물체를 눌러서 합니다. 고정 버튼은 위 줄 아이콘뿐입니다.

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ 섬 이름 ☀ 142/160  ▣ 23                     P 주차 중 14:32   📋 3   ⚙ │
│                                                                         │
│   🚚(택배!)            🍞 ← 완성품                                       │
│     정류장 ──── 빵집 ──── 광장(🐶 🦆 ♥) ──── 꽃집                       │
│     🚗 내 차          ⋯ 빈 땅 ⋯          정비소 🐱🔧                    │
│                                                                         │
│                     (주민이 돌아다니고 낮·저녁·밤이 바뀜)                │
└─────────────────────────────────────────────────────────────────────────┘
```

| 누르는 것 | 열리는 것 |
|---|---|
| 정류장 🚚 | S03 택배 |
| 빈 땅 | S04 짓기 |
| 시설 | S06 시설 말풍선 |
| 광장의 주민 | 쓰다듬기 (♥, 창 없음) |
| 정비소 | S08 차량 관리 |
| 📋 | S07 일일 임무 (화면을 덮는 전체 화면) |

## 8. 차량 상태별 동작

| 상태 | 화면 | 조작 |
|---|---|---|
| 주차 | S01과 모든 화면 | 전부 |
| 주행, 정차, 판단 불가 | S02 | 없음 (GAM-N01, GAM-Q11) |
| 실제 경고 | 어떤 화면이든 위에 S10 | 경고가 풀릴 때까지 유지 (GAM-N02) |

주행이 시작되면 열린 창을 닫고 짓기는 취소합니다. 자원은 차감하지 않습니다(GAM-020).

## 9. 시연 영상 순서 (1차)

| 순서 | 장면 | 화면 |
|---|---|---|
| 1 | 낮의 섬. 주민이 돌아다님 | S01 |
| 2 | 출발 → 주행 모드. 조작 없음 | S02 |
| 3 | 주차 → 차가 돌아옴 → 택배 열기 | S03 |
| 4 | 빈 땅에 시장 짓기 → 저녁 야시장 | S04, S05 |
| 5 | 일일 임무 완료 → 활약도 100 | S07 |
| 6 | 정비소 주민의 정비 알림 → 교체 기록 | S08, S09 |
| 7 | 공기압 경고 → 경고 카드 + 길 일렁임 → 해제 | S10 |

## 10. 출시 후 확장 (PT에서 말로만)

주민 인연 스토리, 계절 이벤트와 무료 시즌 패스, 건축 테마, 음성 조회(GAM-010, GAM-015), 운전 습관 기반 정비 주기(GAM-013).
