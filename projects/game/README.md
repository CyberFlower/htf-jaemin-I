# 내 차로 짓는 도시 (`GAM`)

운행과 소모 기록으로 보상을 얻어 원하는 모습으로 도시를 키운다. 도시를 보러 오는 길에 차량 관리 시기도 알아차린다.

## 심사자가 먼저 볼 것

1. [PROPOSAL.md](PROPOSAL.md): 접수양식 02 원고
2. [SCENARIO.md](SCENARIO.md): 대표 시나리오 "토요일 장보기"의 장면 9개와 캡처
3. [SDK.md](SDK.md): **Pleos SDK 활용 맵**. 게임의 각 장면에 어떤 Pleos API와 퍼미션을 쓰는지 정리했습니다
4. [HTML 목업](../../spikes/game-isometric/README.md): `spikes/game-isometric/index.html`을 브라우저로 엽니다. 차량 신호는 시뮬레이터 값이고, SDK에는 아직 연결하지 않았습니다.
