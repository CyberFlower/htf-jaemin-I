## 3. 장면별 상세

### SC-01 기억

- 상황: 지난 외출 때 카페 앞에 정차한 운전자. 함께 탄 할머니가 "저 카페 가보고 싶다"고 말한 직후입니다.
- 사용자 행동: 홈(S01)의 🎙 기억 남기기를 직접 눌러 "할머니가 저 카페 가보고 싶대"라고 말합니다. 주변 후보 중 바다 카페를 고르고 함께 갈 사람으로 할머니를 고릅니다(GRD-UC-002 B1~B3).
- 앱 응답: 한마디를 텍스트로 받고, 현재 위치 주변의 장소 후보를 보여 줍니다. 사용자가 확인한 장소만 '할머니와 다음에 갈 곳' 약속 카드(S03)로 저장합니다.
- 차량 신호·SDK: SpeechToText — 문서 확인, FusedLocation `getLastKnownLocation` (FUSED_LOCATION) — 문서 확인, 장소 검색 외부 API — 확인 필요 (GRD-Q5), 주행/정차 판단 — 확인 필요 (Q8)
- 오판 방지·대체 동작: 상시 녹음 없이 사용자가 시작할 때만 듣습니다. 주행 중이면 입력을 정차 후로 미룹니다(E1). 위치나 후보를 얻지 못하면 확인할 수 없는 장소를 저장하지 않습니다(E2, 대체 방법은 GRD-Q14). 음성 대신 텍스트로도 입력합니다(A1).

- 사용자 행동: 홈 ‘여정 준비’ → 이번 동행 선택 → 추천 두 곳 비교 → 경유 후보 최대 두 곳 담기 → 내비 적용 승인 시연 → 여정 마치기 → 실제 방문 기록.

- 차량 신호·SDK: 현재는 로컬 시연입니다. 실제 NaviHelper·STT·차량 제한 상태를 읽지 않습니다. 실제 앱에서 쓸 API는 [SDK.md](SDK.md) 2절 SC-08 행(NaviHelper `getDestinationInfo()` → `onDestinationInfo`, FusedLocation, SpeechToText, 경로 적용)이고, 검증 계획은 [API-ADOPTION.md](API-ADOPTION.md)를 따릅니다.
- 오판 방지·대체 동작: 다른 장소의 동행 기억을 질문하지 않습니다. 예정 동행과 실제 방문 동행을 분리합니다. 담기·내비 성공 시연·여정 종료로 스탬프를 만들지 않습니다. 검색 실패·내비 실패/취소·상태 미확인 입력 제한을 시연 설정에서 비교합니다.
