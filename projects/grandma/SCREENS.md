# 화면 구성 (제안): 다녀왔습니다 (`GRD`)

> 상태: **Draft (제안)**, 2026-11-14 (2026-11-15: 목업 화면 대응 갱신, 화면 언어 "실로 잇는 기억" 추가). 공모전(1차 2026-11-15 제출, 2차 2026-12-03 PT)에서 보여줄 장면과 화면을 한곳에 모읍니다. 채택 여부는 팀이 정합니다.
> 화면 ID(`S##`)는 [USE_CASES.md](USE_CASES.md) "화면 흐름 (제안)"의 표기를 그대로 씁니다. 화면 정의는 그 절에만 두고, 이 문서는 링크와 대응표만 둡니다.
> 원천: [GOAL.md](GOAL.md), [USE_CASES.md](USE_CASES.md), [REQUIREMENTS.md](REQUIREMENTS.md), [SCENARIO.md](SCENARIO.md), [SCENARIOS.md](SCENARIOS.md), [목업 README](../../spikes/grandma-journey-context/README.md), [DISPLAY-SPEC.md](../../spikes/grandma-journey-context/docs/DISPLAY-SPEC.md). 어긋나면 원천을 따르고 이 파일을 고칩니다.

## 1. 보여줄 것

- **약속이 실제 하루가 되는 여정:** 정차 중 남긴 "다음에 같이 가자"가 조율 → 출발 → 동행 → 다녀옴으로 이어집니다([GOAL.md](GOAL.md) 대표 시나리오).
- **기억이 다음 질문을 바꾸는 재방문:** 같은 장소를 다시 고르면 지난 방문을 근거로 이번 동행을 묻고, 답에 따라 들를 곳과 이유가 달라집니다([SCENARIOS.md](SCENARIOS.md) 1절).
- **차는 관측하고 사람이 확정:** 도어·정차·위치는 질문의 계기일 뿐이고, 탑승·방문·실행은 사용자가 확인하고 승인합니다(GRD-N02, GRD-005).

### 화면 언어: 실로 잇는 기억 (2026-11-15)

웹 대시보드(왼쪽 메뉴, 큰 카드, 타일)를 걷어 내고, 앱의 정의("기억을 다음 약속으로 잇는다")를 화면 위쪽의 실 한 줄로 보여 줍니다. 비교한 세 방향과 고른 이유는 [화면 콘셉트](../../spikes/grandma-ui-concepts/README.md)에 있습니다. 시각 규칙은 [DISPLAY-SPEC.md](../../spikes/grandma-journey-context/docs/DISPLAY-SPEC.md)를 따릅니다.

| 요소 | 화면 | 뜻 |
|---|---|---|
| 실 | 화면 위쪽에 늘어진 실. 지나온 구간은 꼬인 실, 아직 안 간 구간은 점선 | 기억과 약속이 이어져 있음 |
| 사진 | 확인한 방문은 빨래집게로 건 폴라로이드와 손글씨 설명 | 다녀온 곳 |
| 꼬리표 | 아직 가지 않은 약속은 손글씨 꼬리표. 빈 꼬리표는 "다음 약속" | 다음 약속 |
| 빈 사진틀 | 기억을 남길 자리의 "?" 사진틀 | 지금 채울 기억 |
| 빛 | 운전자의 빛(호박색), 동행자의 빛(분홍, 할머니는 얼굴 그림) | 지금 어디에, 누구와 |
| 매듭 | 방문을 확인하면 꼬리표가 사진으로 바뀌고 실에 매듭 | 약속을 지킴 |
| 하늘빛 | 시간대에 따라 오후·아침·저녁 하늘. 주행 중에는 어두운 배경과 전구 줄처럼 빛나는 실 | 하루의 흐름 |

- 화면 아래쪽에는 질문 한 문장과 큰 대답 버튼을 두 개까지만 둡니다. 메뉴는 앱 이름 옆의 글자 메뉴(홈·둘러보기·발자국·지도·담은 곳)입니다.
- 할머니는 실제 사진이 아니라 가족 역할 그림(은발 쪽머리, 안경)입니다. 실제 사진을 쓸지는 정하지 않았습니다.
- 도어 열림→닫힘은 동행자 자리에 흐린 점선 원을 띄울 뿐입니다. 운전자가 답해야 빛이 채워집니다(GRD-N02).
- 글꼴은 Gowun Batang(제목), Nanum Pen Script(기억·인용의 손글씨), Noto Sans KR(본문)입니다. Google Fonts에서 받고, 차량 앱에 넣을 수 있는지는 확인 필요입니다.

## 4. 차량 상태별 동작

| 상태 | 화면 | 조작 | 근거 |
|---|---|---|---|
| 정차 | S01과 모든 화면 | 입력, 확인, 승인 | USE_CASES "접점", GRD-002 |
| 주차 | S01과 모든 화면. 귀가 카드(S10 진입) | 입력, 확인, 승인 | 지금 카드 규칙 4순위 |
