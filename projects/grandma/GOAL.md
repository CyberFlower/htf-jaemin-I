# GOAL: 다녀왔습니다 (`GRD`)

목표, 타깃, Goal과 Non-goal, 대표 시나리오, 성공 기준, 원칙입니다. 상태는 Draft입니다.

- 기준: [PROPOSAL.md](PROPOSAL.md), [SCENARIO.md](SCENARIO.md), [SCREENS.md](SCREENS.md), [원본 기획안](../../draft/proposal-grandma.html)
- 형식: [공통 UC·FR 템플릿](../../docs/process/templates/README.md)

## 한 줄 정의

가족과 나눈 "다음에"를 한 올씩 이어, "다녀왔습니다"로 매듭짓는 차 안의 동행 앱입니다.

### 제품 목적

사람·장소·기억·약속에 이번 여정의 동행자, 환경, 차량 상태를 연결해, 운전자가 이번 여정을 판단하고 준비하는 데 필요한 정보로 돌려줍니다. 확인된 여정 결과는 다음 안내의 맥락이 됩니다.

가족 동행은 이 목적을 보여 주는 대표 시나리오입니다. 가족 외 타깃으로의 확대는 정하지 않았습니다.

중심 경험([GRD-UC-011](USE_CASES.md))의 기준:

- 같은 목적지라도 확인된 동행자, 약속, 현재 조건이 달라지면 안내가 달라집니다.
- 안내에는 왜 지금 이 사용자에게 관련 있는지, 어떤 기억·관측·외부 정보에 근거하는지가 드러납니다.
- 모르는 정보와 확인된 정보를 구분하고, 잘못된 맥락은 사용자가 고칠 수 있습니다.
- 확인된 방문, 약속 완료, 다음 의도가 이후 여정 안내에 반영됩니다.

정보 선정, 안내 시점, 기억 갱신의 세부 정책은 미정.

### 독립 개발사 앱의 가치 제안

차량 기본 탑재 앱이 아니라 별도 개발사의 앱을 전제로 합니다. 제조사만의 데이터 접근이나 모든 차종 지원을 전제하지 않습니다.

- **중심 경험:** 다시 가는 장소의 지난 동행 기억을 근거로 이번 동행을 묻고, 답에 맞는 정보와 들를 곳을 제시합니다(UC-012 → UC-011). 실제 탑승 확인(UC-006)과는 구분합니다.
- **맥락 품질:** 사용자가 안내 근거를 확인하고, 잘못된 기억을 고치거나 활용에서 제외합니다(UC-014).
- **내 AI(선택 기능):** 운전자가 등록한 Claude, ChatGPT, Gemini API 키로, 앱이 모은 후보 안에서 들를 곳을 이유와 출처를 붙여 정리합니다([GRD-019~021](REQUIREMENTS.md), D-001). 연결하지 않아도 모든 흐름이 동작합니다.
- **다른 차량에서 이어 쓰기(확장):** 기억은 차량 기기에 저장합니다. 다른 차량으로 옮기려면 사용자가 직접 내보내고 가져와야 하며, 지원 범위는 미정(UC-013).

비교할 가치는 기능의 개수보다, 같은 장소에서도 개인의 기억과 이번 답에 따라 달라지는 질문과 안내입니다. 제조사도 만들 수 있는 기능이므로 경쟁력은 따로 검증해야 합니다.

## 문제

- 가 보고 싶다던 곳은 채팅방에, 가능한 날짜는 캘린더에, 함께 찍은 사진은 사진첩에 흩어집니다. 내비게이션에는 주소만 남습니다.
- 누구와, 왜 가려 했는지가 남지 않아 약속은 미뤄지고, 다녀온 기억도 다음 여정으로 이어지지 않습니다.
- 이 불편을 직접 보여 주는 근거(인터뷰, 설문)는 아직 없습니다.

## 타깃 (가설)

- 주 사용자: 따로 사는 부모님이나 조부모님을 차로 모시고 다니는 운전자
- 참여자: 함께 타는 가족. 차량 앱을 설치하지 않습니다. 공유 페이지로 후보를 고르는 기능은 다음 단계입니다
- 규모와 근거: 미정

## Goals

| ID | 목표 | 심사 |
|---|---|---|
| GRD-G1 | 저장한 "다음 약속"(사람 + 장소)이 계획, 출발, 동행, 다녀옴을 거쳐 실제 여정으로 완료되는 흐름을 처음부터 끝까지 보여 줍니다 | `[차량특화]` `[창의]` |
| GRD-G2 | 차량이 여정의 관측과 실행을 맡습니다. 차량 상태로 출발을 준비하고, 승인한 목적지와 경유지를 내비게이션에 넣고, 정차 중에 동행을 확인합니다 | `[차량특화]` `[기술]` |
| GRD-G3 | 사용자가 승인한 범위 안에서만 실행하고, 관측(신호)과 해석(의미)을 구분해 신뢰를 지킵니다 | `[차량특화]` `[창의]` |
| GRD-G4 | 다녀온 기억이 다음 여정 후보로 이어지는 반복 루프를 만들고, 이를 측정할 지표를 정합니다 | `[사업]` |

> 핵심 결과물은 잘 쓴 일기보다 **실제로 함께 다녀온 하루**입니다.

## Non-goals

- 상시 녹음, 기록에 없는 대화나 감정 생성
- 가족관계 자동 추정, 전화번호로 위치 알아내기
- 비공개 채팅, 사진, 연락처 자동 읽기
- 주행 중 화면 조작 요구
- 출발 소식 자동 발송 (수신 동의, 발송 경로, 중복 방지를 검증한 뒤 확장)
- 명절 귀성, 공항 배웅, 가족 여행 시나리오 (같은 구조로 확장할 후속 시나리오)

## 대표 시나리오

**"이번 일요일, 할머니와 바다 카페"**

| 단계 | 장면 | 차량과의 연결 |
|---|---|---|
| 1. 기억 | 지난 외출 때 정차한 자리에서 마이크를 누르고 "할머니가 저 카페 가 보고 싶대"라고 말합니다. 근처 장소 후보에서 바다 카페와 할머니를 골라 약속으로 저장합니다 | 위치, 음성 인식, 정차 상태 |
| 2. 계획과 승인 | 약속에서 여정을 만들고 날짜를 말로 정합니다. 날씨·장소 정보를 출처와 함께 확인하고, 실행할 일을 하나씩 승인합니다 | (차량 밖 정보) |
| 3. 출발 | 연료나 배터리와 날씨를 다시 확인해 필요한 경유지를 제안하고, 승인한 구간을 내비게이션에 넣습니다 | 차량 상태, 내비게이션 |
| 4. 함께 출발 | 할머니 댁 앞에서 문이 열렸다 닫히면 동행을 묻습니다. 운전자가 답해야 할머니의 빛이 켜지고 다음 구간이 들어갑니다 | 도어, 내비게이션 |
| 5. 다녀옴 | 주차 후 방문을 확인하면, 관측과 출발 때의 답으로 미리 채운 한 장짜리 기록에 한마디만 말로 남깁니다. 약속이 완료되고 실에 매듭이 지어집니다 | 위치 기록, 음성 인식 |

같은 곳에 다시 가는 날(SC-08)에는 지난 동행 기억으로 이번 동행을 묻고, 답에 맞춰 들를 곳을 제안합니다. 내 AI를 연결했다면 AI가 이유와 출처를 붙여 정리합니다.

## 성공 기준 (데모)

- [ ] 대표 시나리오 다섯 단계와 재방문을 한 앱의 흐름으로 시연합니다
- [ ] 승인한 목적지와 경유지가 내비게이션에 들어가는 장면이 있습니다
- [ ] Virtual Console에서 바꾼 차량 상태가 출발 준비 안내에 반영됩니다
- [ ] 오판 방지: 문만 열기, 좌석에 짐 놓기, 경로만 탐색하기를 탑승, 방문, 출발로 확정하지 않습니다
- [ ] 입력은 대부분 말로 하고, 운전자는 틀린 것만 고칩니다
- [ ] 네트워크가 끊기거나 내 AI가 응답하지 않아도 확정한 계획과 기록이 유지되고 기본 추천으로 이어집니다

## 원칙

- **관측과 해석을 구분합니다.** 정차는 방문 확정이 아니고, 좌석 점유는 신원 확인이 아닙니다. 지연을 사고로 단정하지 않습니다.
- **AI는 계획을 돕고, 실행은 여정의 상태와 규칙을 따릅니다.** 생성한 문장이 그대로 차량 제어 명령이 되지 않습니다.
- **승인한 범위 안에서 실행합니다.** 경로, 공조, 전송을 각각 따로 승인합니다.
- **기억은 차량 기기에 저장하고, 밖으로는 필요한 것만 보냅니다**(GRD-N06).
- 기억의 출처와 갱신 시각을 보존합니다. 공유 콘텐츠와 실행 명령을 분리합니다. 전송 중복을 막고 실행 결과를 확인합니다.

여정 상태: `제안 → 계획 → 확정 → 준비 → 이동 → 회고`

## 사업성 메모

- 반복 사용 동인: 다녀온 기억이 다음 여정 후보가 됩니다.
- 측정 후보: 다음 약속을 남긴 비율, 저장한 약속의 여정 전환율, 기록 완료율, 불필요한 확인 횟수
- 확장: 명절 귀성, 공항 배웅, 가족 여행
- 개인화 방향: 운전자가 연결한 AI(Claude, ChatGPT, Gemini)가 가족 기억과 대한민국 명소발굴 (100×100)·관광 정보 후보 안에서 들를 곳을 정리합니다. 보내는 범위는 최소이고, 실행은 운전자 승인으로 합니다([GRD-019~021](REQUIREMENTS.md)).
- 제휴·수익 방향: 공공 관광 데이터·지역 추천 목록과 연계한 "함께 갈 만한 곳", 지자체·관광 기관과의 가족 방문 캠페인. 제휴 장소는 제휴임을 밝히고 선택지로만 제안합니다. 명절·장거리 이동 전 차량 점검 안내와 연계합니다.
- 내 AI 비용 구조: 요금은 사용자의 API 계정으로 청구되어, AI 기능이 늘어도 운영비가 함께 늘지 않습니다. 내 AI는 선택 기능입니다(D-001).
- 타깃 규모, 예상 MAU, Retention의 근거: 아직 없음. 초기 사용자 검증으로 확인합니다
