# 심사 기준과 점검표

> 출처: <https://appdevchallenge.auto-hmg.io/guide/judging-awards> (확인일 2026-11-12)
> 공지사항으로 바뀔 수 있으니 제출 직전에 다시 확인합니다. 공식 내용과 팀 해석은 구분해 표시했습니다.

## 1. 심사 단계

| 단계 | 대상 | 기준 | 비고 |
|---|---|---|---|
| 1차 서류심사 | 전체 접수작 | 아래 필수 4개 항목 + 개발 산출물 가산점 | 세부 배점 비공개. 결과 발표 2026-11-23 |
| 2차 PT 심사 (오프라인) | 1차 합격팀 | **미공개** (추후 공지) | 2026-12-03~04. PT에서 제출·시연한 결과물로 수상작과 순위 확정. **PT 전까지 실제로 동작하는 앱 필요** |
| 최종 선정 | 10팀 | — | 2026-12-18 발표. 2027-02 그룹 행사에서 전시·시상, 현장 시연용 release APK 제출 필수 |

- 1차 접수 때 낸 산출물은 2차 PT 전까지 자유롭게 고도화할 수 있습니다.
- 최종 선정 뒤 전시 준비 기간(2026-12-19~2027-01)은 추가 개발 기간이 아닙니다. 영상 제작과 APK 구동 테스트를 하는 기간입니다. PT 이후의 버그 수정은 허용되지만 순위에는 영향을 주지 않습니다(FAQ).

## 2. 1차 평가 항목

| 항목 | 태그 | 공식 평가 내용 (요약) | 점검 질문 (팀 해석) |
|---|---|---|---|
| 차량특화성 (필수) | `[차량특화]` | 모바일 대비 차량 환경만의 독자적 가치와 우위가 있는지, 주행·정차 상황과 차량 기능이 유기적으로 결합되었는지 | 같은 기능을 폰 앱으로 만들면 무엇이 사라지는가? 주행 중과 정차 중에 각각 어떻게 동작하는가? |
| 창의성 (필수) | `[창의]` | 기존에 없던 독창적·혁신적 아이디어인지, 운전자·동승자의 Pain Point와 니즈를 명확히 정의하고 해결 방식이 분명한지 | 누가, 어떤 순간에 겪는 불편인가? 기존 해결책(내비 즐겨찾기, 정비 알림 앱 등)과 무엇이 다른가? |
| 기술 활용성 (필수) | `[기술]` | Pleos Playground가 제공하는 SDK·API를 핵심 기능과 사용 경험에 적절히 활용했는지 | 어느 SDK의 어느 API가 어느 장면에 쓰이는가? 장식이 아니라 핵심 흐름에 쓰이는가? 에뮬레이터에서 검증했는가? |
| 사업성 (필수) | `[사업]` | 타깃 고객이 명확한지, 사용자 확보와 지속 이용·확대 가능성이 있는지. 예: 타깃 고객 분석, 예상 MAU, Retention Rate, 향후 서비스 확대 계획 | 타깃은 누구이고 규모는 얼마인가? 왜 다시 쓰는가? MAU·Retention 가정의 근거는 무엇인가? |
| 개발 산출물 (가산점, 선택) | — | 프로토타입 시연 영상(화면 녹화 포함), GitHub 저장소(소스 코드 + APK). 제출 수준에 따라 단계별 가산점 | 영상에 대표 시나리오가 처음부터 끝까지 나오는가? 차량 신호가 바뀌는 장면이 보이는가? |

요구사항마다 위 태그를 하나 이상 붙입니다. 형식은 [requirements-guide.md](../process/requirements-guide.md)를 따릅니다.

## 3. 접수양식 항목과 심사 항목 (팀 해석)

접수양식 "02 앱 프로젝트 소개 / 심사 자료"가 1차 심사 자료입니다. 각 프로젝트의 `PROPOSAL.md`가 이 항목의 원고입니다.

| 양식 02 항목 | 주로 대응하는 심사 항목 |
|---|---|
| 1. 앱 한 줄 소개 | 전체 |
| 2. 기획 배경 | 창의성 (Pain Point, 니즈) |
| 3. 앱 주요 기능 및 차량 특화 요소 | 차량특화성, 창의성 |
| 4. 주요 사용 시나리오 | 차량특화성 |
| 5. 개발 계획 (SDK/API 사용 계획) | 기술 활용성 |
| 6. 기대효과 및 발전 가능성 (타깃, MAU, Retention, 확대 계획) | 사업성 |
| 7. 참고자료 (화면 시안, 시연 영상, GitHub) | 개발 산출물 가산점 |
| 8. 숏폼 링크 | 별도 특별상, 가산점 없음 |

## 4. 시상

총상금 5,100만원. 아이디어 특별상은 대학생·일반 부문을 통합해 선정합니다.

| 상격 | 상금 | 수상 팀 수 |
|---|---|---|
| 대상 | 1,000만원 | 대학생 1, 일반 1 |
| 최우수상 | 600만원 | 대학생 1, 일반 1 |
| 우수상 | 400만원 | 대학생 2, 일반 2 |
| 아이디어 특별상 | 150만원 | 부문 통합 2 |
| 숏폼 챌린지 어워드 (별도) | 50만원 | 1 |

수상팀 지원: Pleos App Market 탑재 준비 지원(별도 검증·심사, 입점 보장 없음), 2027-02 그룹 행사 전시·시상.
