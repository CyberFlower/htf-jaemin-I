# 차량 디스플레이 설계 기준

Draft · 2026-11-13 · 실험 목업

사용자가 확정한 규격은 14.6인치, 16:9 가로, 1920×1080이다. 논리 화면은 1280×720이며 1.5배에서 기준 픽셀 크기가 된다. 활성 화면의 물리 크기는 약 323×182mm, 약 151ppi다. 브라우저 창에 맞춘 축소 화면은 실제 14.6인치 크기를 보장하지 않는다.

## 구성 · 2026-11-14 터치 화면 개정

- 홈: 지금 할 일 카드 하나와 발자국·주제 탐색 진입. 여정 준비와 방문 기록을 이어 준다.
- 추천 화면: 목적지·동행 요약, 여정 설정, 추천 카드 두 장, 이전·다음. 지도·필터·방문 패스포트는 함께 표시하지 않는다.
- 카드: 장소명, 종류·예시 이동 시간, 방문 여부, 추천 이유 한 줄. 카드 전체가 하나의 터치 영역이며 담기는 상세 화면에서 수행한다.
- 여정 설정: 목적지·동행·취향·분류·새로운 곳 우선. 과거 동행 확인은 이 화면에서 제시한다.
- 지도: 장소 핀과 방문 스탬프를 별도 화면에서 탐색한다.
- 발자국: 방문 기억의 확인·편집 화면.
- 상세 → 추천 이유와 정보 출처: 사용자가 원할 때 설명을 단계적으로 확장한다.
- 전체 그래프와 JSON: 화면 밖 제작 검토 도구. 사용자 주 메뉴에서는 제거한다.
- 상단 72, 본문 584, 하단 64의 차량 화면 구조와 1280×720 논리 좌표는 유지한다. 하단 공조 표시는 별도 개발사 앱이 차량 기능을 제어한다는 뜻이 아니다.

주요 버튼·입력은 논리 높이 64 이상, 버튼 사이 간격은 16~24를 기준으로 한다. 지도 핀·스탬프도 64다. 기준 해상도에서 64 논리 단위는 96픽셀, 약 16mm다. 그래프 노드와 브라우저 밖 검토 도구는 이 사용자 화면 기준 대상에서 제외한다. 실제 차량의 시야 거리·장착 각도·밝기·입력 지연·플랫폼 가이드는 별도 검증해야 한다.

사용자 문구는 ‘조용한 곳을 좋아하셔서’, ‘지난번 어머니와 다녀온 곳이에요’처럼 장소 선택에 필요한 이유를 쓴다. 구조·계산 방식의 설명은 제작 검토 도구에 둔다. 가상 정보라는 표시는 시연 도구와 정보 출처에서 확인할 수 있다.

주행·차량 상태 미확인 시연에서는 본문과 메뉴를 inert 처리하고 입력도 코드에서 차단한다. 주행이면 본문과 메뉴 자리를 S09 주행 모드(다음 목적지·남은 시간·음성 안내 한 줄)가 덮는다. 화면 밖 시연 도구로 정차로 전환하면 기존 맥락과 여정 후보가 유지된다. 내비 승인·응답 대기·성공·실패·취소는 시연한다. 실제 차량 상태 수신·음성 제어·내비게이션 연동은 구현하지 않았다.

## 차량 제조사 앱과 비교해 검증할 가설

차량 제어보다 사람의 기억과 목적지 주변 장소 지식의 연결에 집중한다. 같은 사람이 다른 지원 차량을 이용해도 취향·방문 맥락을 이어가는 것이 제품 방향이다. 이번 목업의 localStorage는 현재 브라우저만 저장하므로 차량 간 이동을 구현한 것은 아니다.

추천 전문성은 그래프의 시각적 복잡도가 아니라 확인 가능한 장소 속성, 사용자에게 확인한 동행 선호, 이전 경험을 현재 여정에 적용하는 품질에서 나온다. 설명을 읽고 후보를 선택할 수 있는지, 잘못된 기억을 고친 뒤 추천이 바뀌는지로 평가한다.

## 검증 범위

구문 검사와 jsdom 상호작용 검증 통과. 기준 배율 계산, 두 장 페이지 이동, 필터 초기화, 추천 근거, 동행 예정/실제 방문 분리, 기록 편집·제외·삭제, 입력 제한, 저장을 확인했다.

관리형 미리보기 relay 준비 시간 초과 및 공유 브라우저 초기화 오류로 실제 화면 렌더링 검증은 미완료다. 글자 잘림, 모달 스크롤, 지도 핀 겹침, 터치 타깃, 확대 화면의 가독성은 실제 브라우저 및 대상 디스플레이에서 후속 확인해야 한다. jsdom 검증은 시각 검증을 대체하지 않는다.


## 방문 기록 입력 방식 개정

텍스트 박스와 네이티브 날짜 입력을 제거했다. 날짜·동행·한마디·확인을 한 단계씩 보여주고 주요 선택 버튼은 64 논리 단위 이상을 유지한다. 문구 선택 및 음성 시연을 제공하며, 한마디 없이도 저장 가능하다. 음성 시연에는 실제 녹음이 없다는 표시를 넣고 인식 결과 확인·재시도·취소·실패 복귀를 구분했다. 실제 음성 인식과 차량 마이크 연결은 포함하지 않는다.

## 하루 흐름 통합 · 2026-11-15

- 홈의 지금 카드 하나가 차량 상태에 따라 바뀐다. 순서: 주행(S09) > 도어 관측 동행 후보 > 오늘 계획 > 귀가 후 다녀옴 확인 > 저장한 약속·기억 남기기. 첫 방문 기록 뒤에는 재방문 카드.
- 첫 방문 화면(S02·S03·S04·S06·S07·S08)은 본문 584 안에서 머리 64 · 내용 · 하단 버튼 64 구조를 쓴다. 출발 준비와 동행 확인은 하단 버튼 줄 없이 내용 안에 적용 버튼을 둔다.
- S09 주행 모드는 본문과 메뉴 영역 전체(1280×584)를 덮고 버튼이 없다. 상단 72와 하단 시스템 64는 그대로 보인다.
- 시연 도구는 차량 화면 밖 오른쪽(폭 272px)에 둔다. 차량 상태 조작만 있고 장면 이동 버튼은 없다. `embed=1`이면 숨긴다. 이 도구는 사용자 화면 기준(64 터치 등)의 대상이 아니다.
- 색: 크림 배경 `#f7efe3`, 종이 `#fffaf2`, 글자 `#3b2a20`, 주색 테라코타 `#b4532a`(흰 글자 4.99:1), 보조 글자 `#76604f`(종이 위 5.68:1), 주행 모드 배경 `#2b1f18`(글자 13.7:1). 대비는 WCAG 계산값이며 실제 디스플레이에서 확인하지 않았다.
- 2026-11-15에 Chromium 1920×1080에서 각 장면과 시연 도구를 찍어 잘림이 없음을 확인했다. 실제 차량 디스플레이 검증은 남아 있다.

## 화면 언어 개정 · 2026-11-15 (실로 잇는 기억)

[화면 콘셉트](../../grandma-ui-concepts/README.md)의 A+ 방향을 적용했다. 위의 "왼쪽 메뉴"와 "지금 카드 + 그림" 구성은 이 절로 바뀐다.

| 영역 | 크기(논리) | 내용 |
|---|---|---|
| 머리 | 1280×72 | 명조 브랜드, 글자 메뉴(홈·둘러보기·발자국·지도·담은 곳, 높이 48), 날짜, 차량 상태, 시각, 취향 |
| 홈 실 | 1280×300 | 지난 사진(최대 3), 오늘 여정의 정류장, 운전자·동행자 빛, 약속 꼬리표, 매듭 |
| 홈 질문 | 왼쪽 64부터, 높이 284 | 관측 한 줄, 질문(명조 46), 설명, 근거, 대답 버튼 최대 2(높이 68) |
| 홈 바로가기 | 오른쪽 아래 | 기억 남기기·약속·지난 발자국(높이 48) |
| 주행(S09) | 화면 전체 어둡게 | 빛나는 실, 두 빛, "○○까지", 남은 시간(명조 118), 음성 안내 한 줄. 버튼 없음 |

- 배경: 시각에 따라 아침(<11시)·낮(<15시)·늦은 오후(<18시)·저녁. 주행 중에는 머리까지 어둡게 바뀐다.
- 사람: 할머니는 은발 쪽머리·안경 얼굴, 어머니는 갈색 머리 얼굴. 사진 속에는 뒷모습. 실제 사진이 아닌 역할 그림이다.
- 동행 표시 규칙: 도어 관측은 동행자 자리의 흐린 점선 원만 띄운다. 운전자가 [네, 함께 가요]를 누른 뒤에만 빛을 채운다. 아니요면 빛을 그리지 않는다.
- 글꼴: 제목 Gowun Batang, 기억·약속·사진 설명 Nanum Pen Script, 안내·버튼 Noto Sans KR. 모두 Google Fonts(OFL)에서 받는다. 차량 앱에 넣을 수 있는지는 확인 필요. 오프라인이면 기본 글꼴로 대신한다.
- 색: 기존 토큰을 유지하고 하늘빛 그라데이션, 실 `#a8482a`, 동행자 빛 분홍 `#f2b3a0`, 주행 배경 `#1d1511`을 더했다. 새 배경 위 글자 대비는 다시 계산하지 않았다(확인 필요).
- 버튼은 모두 알약 모양이다. 주요 버튼 높이 64~68, 메뉴·바로가기 48. 테두리 있는 웹 카드는 쓰지 않고 반투명 종이 면과 그림자로 묶는다.
- 2026-11-15에 Chromium 1920×1080에서 SC-01~08, 기억 남기기 세 단계, 약속·계획·승인·출발 준비·동행 확인, 방문 기록, 둘러보기·발자국·지도·여정 설정을 찍어 겹침과 잘림을 고쳤다. 실제 차량 디스플레이 검증은 남아 있다.
